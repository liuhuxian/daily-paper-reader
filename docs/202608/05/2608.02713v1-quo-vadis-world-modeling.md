## 摘要
不断改进的智能体需要超越静态监督的动态交互反馈，然而直接与现实环境交互成本高昂、速度缓慢、存在安全隐患且难以并行化。世界建模提供了一种自然的中间代理，使智能体在采取实际行动之前，能够查询成本更低、更可控的反馈。经典世界模型主要通过未来物理状态预测来实例化这一代理，这种表述对于需要超越原始状态转移的可操作反馈的智能体而言虽有用但较为狭隘。在本工作中，我们概念化了“智能体中心交互式世界代理”，将基本范式从物理状态转移转变为智能体可用的信息转移，例如执行结果、检索到的经验或技能以及验证信号，从而拓宽世界建模的范畴，为持续改进的智能体提供多样化反馈。为系统性地描绘这一设计空间，我们根据反馈模态将世界代理组织为六种功能形式：动力学、空间、执行、记忆/经验、技能以及奖励/验证代理，它们共同刻画了世界建模服务于智能体改进的主要方式。我们进一步分析了这些代理如何在三个递进层面赋能智能体：L.1 推理时引导，其中代理输出丰富上下文信息以支持更优决策；L.2 训练时优化，其中代理输出产生奖励、批评或合成轨迹用于策略学习；以及 L.3 智能体-代理协同进化，其中真实环境证据持续更新代理和智能体以实现共同进化。最终，本工作将世界建模重塑为一种智能体中心范式，为构建赋能智能体更好规划、更快学习并持续进化的世界代理确立了路线图。

## Abstract
Continually improving agents require dynamic interaction feedback beyond static supervision, yet direct real-environment interaction is costly, slow, unsafe, and hard to parallelize. World modeling offers a natural intermediate proxy that allows agents to query lower-cost, more controllable feedback before committing to real actions. Classical world models instantiate this proxy primarily through future physical-state prediction, a formulation useful yet narrow for agents that require actionable feedback beyond raw state transitions. In this work, we conceptualize Agent-Centric Interactive World Proxies, shifting the fundamental paradigm from physical state transitions to agent-usable information transitions, such as execution outcomes, retrieved experiences or skills, and verification signals, broadening the scope of world modeling to provide versatile feedback for continually improving agents. To systematically map this design space, we organize world proxies into six functional forms based on their feedback modalities: dynamics, spatial, execution, memory/experience, skill, and reward/verification proxies, which together characterize the primary ways world modeling serves agent improvement. We further analyze how these proxies empower agents across three progressive levels: L.1 Inference-Time Guidance, where proxy outputs enrich in-context information for superior decisions; L.2 Training-Time Optimization, where proxy outputs yield rewards, critiques, or synthetic rollouts for policy learning; and L.3 Agent-Proxy Co-Evolution, where real-environment evidence continuously updates both the proxy and the agent for co-evolution. Ultimately, this work recasts world modeling into an agent-centric paradigm, establishing a roadmap for building world proxies that empower agents to plan better, learn faster, and evolve continually.

- **核心问题**：如何让智能体超越静态监督、通过主动交互获得有用反馈、并无限自我改进？

### 2.2 形式化定义

**定义**：智能体中心世界代理是一个环境锚定（environment-grounded）的代理，建模并预测以智能体主动交互为条件的信息转移，旨在为智能体改进提供信息增益。形式上：

```
ŝ_{ℓ+1} = WP(s_ℓ, u^F_ℓ)，s_ℓ ∈ 𝒮
```

其中：
- **ℓ**：交互步，表示智能体与世界代理的第 ℓ 次交互；
- **𝒮**：信息状态空间，包括物理状态、观测、记忆、知识、执行结果、验证等广义状态；
- **F**：代理功能类型（动力学、空间、执行、记忆、技能、奖励/验证）；
- **u^F_ℓ**：智能体在特定代理功能下主动提出的查询/动作/干预；
- **ŝ_{ℓ+1}**：代理返回的反馈（未来状态、新观测、执行结果、记忆/技能、奖励或验证结果）。

### 2.3 闭环交互流程

论文定义了智能体在世界代理回路中的四个步骤：

1. **智能体发起交互**：根据当前目标、上下文状态等条件，主动提出交互请求 u^F_ℓ；
2. **世界代理预测信息转移**：基于当前信息状态 s_ℓ 和交互 u^F_ℓ，预测或生成反馈；
3. **反馈返回智能体**：预测的 ŝ_{ℓ+1} 作为新的信息增益返回；
4. **智能体利用反馈改进**：用于规划、决策、策略学习或持续改进。

### 2.4 优秀世界代理的五个标准

- **锚定性（Groundedness）**：依赖真实环境数据、规则、轨迹或交互证据；
- **可控性（Controllability）**：支持智能体主动查询并返回对应反馈；
- **反馈有用性（Feedback Usefulness）**：确实改善规划、决策、策略学习或持续改进；
- **成本与可扩展性（Cost and Scalability）**：降低真实交互成本且能安全扩展；
- **前瞻能力（Forward-Looking Ability）**：在真实执行前预判结果、反事实或风险。

### 2.5 三大赋能层次

- **L1 推理时引导**：代理不改动智能体参数，只提供额外上下文（记忆/技能检索、执行模拟、验证反馈），让智能体"看得更多、推理更准、行动更稳"。形式上：s_agent+_ℓ = s_agent_ℓ ⊕ ŝ_guide_{ℓ+1}。
- **L2 训练时优化**：代理充当奖励模型、验证器、批评者或模拟器，生成训练信号重塑策略。形式上：agent⁺ = Train(agent, ŝ_opt_{ℓ+1})。可实现为 Proxy-as-Reward、Proxy-as-Critic、Proxy-as-Simulator、Proxy-Guided Curriculum。
- **L3 智能体-代理协同进化**：真实环境证据更新代理，代理知识蒸馏回智能体，形成闭环共同进化。形式上：(agent⁺, WP⁺) = CoEvolve(agent, WP, ŝ_proxy_{ℓ+1}, s_env_{ℓ+1})。

### 2.6 六种功能形式

- **动力学代理（Dynamics Proxy）**：预测未来状态和奖励（经典世界模型）；
- **空间代理（Spatial Proxy）**：从新视角/位置生成观测（NeRF、3DGS等）；
- **执行代理（Execution Proxy）**：模拟代码、命令、点击、API调用的执行结果；
- **记忆/经验代理（Memory/Experience Proxy）**：检索过去交互的经验、失败案例、约束；
- **技能代理（Skill Proxy）**：检索/推荐可复用的技能或行为先验；
- **奖励/验证代理（Reward/Verification Proxy）**：评估行为正确性、安全性、可行性，输出奖励、批评、偏好或验证结果。

## 6. 主要结论与发现

- **核心结论**：世界建模的正确发展方向不是做"更逼真的世界镜像"，而是成为"有用的对话者"—以智能体为中心的**世界代理**，为持续改进的智能体提供可操作的信息增益。
- **从预测世界到服务智能体**：世界模型的核心评判标准应从"预测准确度/视觉真实感"转向"是否改善了智能体的规划、决策、学习和持续改进"。
- **反馈类型的扩展**：智能体需要的反馈远不止下一状态，还包括执行结果、空间观测、记忆/经验、技能指导、奖励/验证等六种功能形式。
- **赋能路径是递进的**：L1（推理时指导）→ L2（训练时优化）→ L3（智能体-代理协同进化），嵌入深度和影响力逐层增加，但错误代价也随之上升。
- **开放问题清单**：
  - **保真度与想象力的极限**：生成模型可能看起来令人信服却违反物理规律，误差在长程展开中累积，需要校准的不确定性而非更清晰的像素；
  - **何时信任代理**：智能体必须在线判断是依据代理反馈行动还是回到真实环境，目前很少有智能体能做出良好判断；
  - **奖励黑客与安全**：当代理成为奖励/验证器时（L2），智能体可能利用其盲点，需要防范新的攻击面；
  - **评估信息增益**：现有基准孤立地评测代理（如现实性、保真度），需要"智能体中心"基准—反馈是否真的帮助智能体规划、学习、改进。
