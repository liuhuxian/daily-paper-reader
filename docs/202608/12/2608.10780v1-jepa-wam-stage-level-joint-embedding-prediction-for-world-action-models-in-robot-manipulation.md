## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射为跨多样化任务的动作。然而，现有方法通常将未来表示为固定的短时视频-动作块。这种短期未来捕捉用于动作执行的局部场景演化，但它并未明确描述指定任务应如何从当前阶段推进到下一阶段的阶段级未来。因此，我们区分了机器人操作中两种互补的未来：用于捕捉局部场景演化的短期物理未来，以及用于表示任务进度的阶段级语义未来。我们引入了JEPA-WAM，它通过Stage-JEPA增强了基于Motus的世界动作模型（WAM），Stage-JEPA是一种以目标为条件的联合嵌入预测架构（JEPA）预测器。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的总体成功率，并将成功执行中的平均执行步数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

## 2. 论文提出的方法论

- **核心思想**：将任务进度建模为阶段级潜在目标，并通过 JEPA 在表示空间预测该目标（不重建像素），再将目标作为条件注入 WAM 的视觉流，指导短期视频和动作生成。
- **阶段对构造（无人工标注）**：
  - 对每个轨迹每 8 帧采样候选中心，用冻结 V-JEPA2 编码 64 帧片段；
  - 基于片段/令牌级表示距离计算变化分数，经 min-max 归一化和时序 NMS 选出最多 5 个关键帧；
  - 关键帧加上首尾帧构成阶段边界；每个当前帧 \(t\) 与下一个边界 \(b_{i+1}\) 组成稠密训练对。
- **Stage-JEPA 训练**：
  - 冻结 V-JEPA2 编码器，训练从 V-JEPA2 初始化的预测器和指令适配器；
  - 当前片段 \(S_t\) 与目标片段 \(S_{target}\) 分别编码，预测器输出下一阶段 token，经池化和归一化后与目标潜在表示计算余弦损失：
    \[
    L_{stage} = \frac{1}{B}\sum_{i=1}^{B}\left(1 - (\hat{z}_i^{target})^\top z_i^{target}\right)
    \]
- **阶段条件 WAM（Stage II）**：
  - 冻结 Stage-JEPA，以 Motus（Mixture-of-Transformers，包含视频专家、动作专家、视觉语言理解专家）为骨干；
  - 将预测的下一阶段 token 平均池化，经 MLP 映射到视频 token 维度，通过全局标量门控注入视频流：
    \[
    h_t = P_\psi(\text{Pool}(\hat{Z}_t^{target})),\quad \alpha = 0.2\sigma(\beta),\quad \tilde{X}_t^v = X_t^v + \alpha h_t
    \]
  - 总损失为：
    \[
    L = L_{video} + L_{action} + \lambda_g \alpha^2 + \lambda_\rho (\rho - \rho_0)^2,\quad \rho = \frac{\|\alpha h_t\|}{\|X_t^v\|}
    \]
- **闭环推理**：维护 64 帧因果观测缓冲，Stage-JEPA 预测下一阶段潜在目标，WAM 条件生成短时视频和动作块；执行后更新缓冲并重规划。

## 7. 优点

- **概念创新**：清晰地区分“短期物理未来”和“阶段级语义未来”，弥补了现有 WAM 只建模局部动态、不显式建模任务进度的不足。
- **自动阶段标注**：利用冻结 V-JEPA2 特征变化自动推断阶段边界，无需人工标注，扩展性好。
- **JEPA 选择合理**：在表示空间预测目标，避免像素级重建对无关外观的过度关注，使预测更聚焦于任务相关语义状态。
- **模块化架构**：两阶段训练解耦，Stage-JEPA 冻结后不影响 WAM 细节损失，门控注入接口可迁移到其他具有视觉条件流的 WAM。
- **实验验证较全面**：覆盖大规模仿真、多样任务、随机化、消融、执行效率、真实机器人验证，且与多个基线对比。
