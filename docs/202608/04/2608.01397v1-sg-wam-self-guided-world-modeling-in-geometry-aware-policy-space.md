## 摘要
世界动作模型（WAM）将动作生成与未来状态预测相结合。其有效性取决于未来动态是否在与动作生成对齐且具有足够几何感知能力以捕捉动作在何处以及如何改变场景的空间中进行建模。现有的WAM通常仅满足这一要求的一部分，要么依赖于感知负担较重的观测空间目标，要么依赖于未针对动作相关性和几何性进行联合结构的辅助潜在空间。我们提出SG-WAM，一种自引导框架，直接在策略派生的表示空间中学习几何感知的动作条件动态。SG-WAM引入了可学习的动态令牌和自引导世界预测器，该预测器在介入机器人动作的条件下预测其未来潜在状态。预测目标由同一策略主干的指数移动平均副本生成，在动作专家所使用的表示族内提供稳定的监督。几何监督进一步结构化策略图像令牌表示，为动态令牌提供空间上下文化的基础，并产生一个既与动作相关又具有几何感知的未来对齐空间。潜在未来预测、几何基础化和流匹配动作生成在一个统一框架中进行端到端的联合优化。SG-WAM基于0.9B模型，无需大规模具身预训练，在LIBERO上实现了98.5%的平均成功率，在LIBERO-Plus上实现了73%，同时在分布内和分布外的真实世界评估中均优于强基线。

## Abstract
World Action Models (WAMs) couple action generation with prediction of future states. Their effectiveness depends on whether future dynamics are modeled in a space that is both aligned with action generation and sufficiently geometry-aware to capture where and how actions change the scene. Existing WAMs typically satisfy only part of this requirement, relying on either perceptually heavy observation-space targets or auxiliary latent spaces that are not jointly structured for action relevance and geometry. We propose SG-WAM, a self-guided framework that learns geometry-aware action-conditioned dynamics directly in the policy-derived representation space. SG-WAM introduces learnable dynamics tokens and a Self-Guided World Predictor that forecasts their future latent states conditioned on intervening robot actions. Prediction targets are generated by an exponential moving average copy of the same policy backbone, providing stable supervision within the representation family used by the action expert. Geometric supervision further structures the policy image-token representations, providing spatially grounded context for the dynamics tokens and yielding a future-alignment space that is both action-relevant and geometry-aware. Latent future prediction, geometric grounding, and flow-matching action generation are jointly optimized end-to-end in a unified framework. Built on a 0.9B model without large-scale embodied pretraining, SG-WAM achieves 98.5% average success on LIBERO and 73% on LIBERO-Plus, while outperforming strong baselines in both in-distribution and out-of-distribution real-world evaluations.

- **理想需求**：未来建模空间应同时满足——与动作生成直接耦合，且保留表达操作所需的空间/几何细节。
- **核心问题**：如何构建一个**几何感知**且**直接耦合于动作生成策略表征**的未来对齐空间？

## 2. 方法论

**总体思想**：SG-WAM 直接在策略表征空间内学习动作条件的几何感知世界动力学，通过可学习动力学 token 承载场景状态，由 EMA 策略副本提供自引导预测目标，并以冻结的 3D 基础模型（VGGT）注入几何结构，统一优化未来预测、几何接地与动作生成。

### 2.1 核心框架组成

| 组件 | 功能 |
|---|---|
| **可学习动力学 tokens（Q ∈ R^{Nq×D}）** | 插入 VLM 序列，自主学习承载动作相关场景状态的紧凑表征 |
| **VLM 主干（Qwen3.5-0.8B）** | 联合上下文化多视角视觉 token、语言 token 与动力学 token |
| **Self-Guided World Predictor（SGWP）** | 以当前动力学状态为 query，通过自注意力+交叉注意力，预测介入动作序列条件下的未来潜状态 |
| **EMA 目标副本** | 由同一策略骨干的 EMA 参数处理未来观测，生成稳定预测目标（遵循 BYOL 范式，μ = 0.999） |
| **VGGT 几何教师（冻结）** | 对策略主视角图像 token 施加几何监督（余弦相似度对齐），不参与未来预测目标 |
| **流匹配动作专家** | 以完整策略上下文为条件，生成连续动作块 |

### 2.2 关键技术细节

- **自引导世界模型**：
  - 在线分支：当前动力学状态 z^Q_t = P_φ(H^Q_t)，经动作编码器 A_η 编码介入动作序列 eA_t，SGWP 预测未来状态 ẑ^Q_{t+Δ} = F_ψ(z^Q_t, eA_t)；
  - 目标分支：EMA 策略处理未来观测 V_{t+Δ} 与同一条指令，产生目标状态 z̄^Q_{t+Δ}（梯度截断）；
  - 损失：L_pred = (1/N_q d)‖ẑ^Q_{t+Δ} − sg(z̄^Q_{t+Δ})‖²_F；
  - 介入动作为八步序列（与动作块长度一致），保留时间顺序。
- **几何监督**：
  - 冻结 VGGT-1B 提取主视角图像的几何特征（单帧 518×518，37×37 patch → 8×8 自适应池化）；
  - 逐 token 投影器将对齐到该特征空间，采用余弦相似度损失：L_geo = (1/N_mv)Σ[1 − cos(Ẑ^G_t,j, Z^G_t,j)]；
  - 关键设计：几何特征仅塑造视觉上下文，不定义预测目标。
- **动作专家**：条件流匹配——给定动作块 A_t 与噪声 ε，插值 A^τ_t = τA_t + (1−τ)ε，回归速度场 ||v_ω(A^τ_t, τ, H_t) − (A_t − ε)||²₂。
- **联合训练目标**：L = L_act + λ_geo·L_geo + λ_pred·L_pred（λ_geo = 0.1，λ_pred = 0.1），所有在线组件单阶段端到端联合优化。
- **推理时**：VGGT 教师、SGWP 预测分支和 EMA 目标路径全部移除，仅保留在线 VLM、动力学 tokens 和动作专家。

## 6. 主要结论与发现

1. **核心主张成立**：在策略表征空间中自引导预测 + 几何监督的有效性得到验证——0.9B 模型达到与 7B 级最强基线相当甚至更好的性能；

3. **LIBERO-Plus 鲁棒性**：零样本总体成功率 73.0%，为所有方法中最高；在相机、语言、光照、布局扰动下取得最优，背景与噪声扰动下保持竞争性——表征对视觉/语言分布偏移不敏感；
4. **真实世界泛化**：ID 与 OOD 条件下均优于 VPP 和 VLA-JEPA，特别是在长程 Toolbox Organization 任务（50%）上优势明显；
5. **消融结论**：
   - 世界建模贡献（1.9pp）> 几何监督贡献（0.9pp），二者互补，在 Long 任务上增益最大；
   - 8 个动力学 token 最优（98.5%）；增至 16 个反降至 97.2%——适度 token 数足以表征交互动态；
   - 空动作序列变体（97.6%）低于真实动作条件（98.5%），证明介入动作信息对长程未来状态预测有实质贡献；
   - 几何监督使动力学 token 的注意力更集中于机器人-物体交互区域，而非孤立视觉显著物体。

## 7. 优点

- **方法设计层面**：
  - 未来预测目标来自**同一策略体系**（EMA 副本），从根源上消除目标-策略失配；
  - 几何监督采用**余弦方向对齐**而非特征回归，避免过度约束 VLM 隐藏状态幅值/分布，保持预训练表征兼容性；
  - 动静结合：SLAM/VGGT 教师仅训练时使用，推理零额外开销；
  - 单阶段端到端训练，无阶段式微调或辅助预训练依赖；
  - 0.9B 参数即可达到大模型性能，计算效率高。
- **实验设计层面**：
  - LIBERO-Plus 七维扰动覆盖全面，能有效检验表征的分布外稳健性；
  - 真实世界任务选取互补性强（刚性抓取/可变形/长程多物体），OOD 条件设计合理；
  - 消融体系完整，含 token 数量（容量）与动作条件（信息量）两个非常规视角。

## 8. 不足与局限

- **实验覆盖不足**：
  - 真实世界仅 3 个任务、2 个基线的对比，结论外推到更广泛操作场景的证据有限；
  - 未进行多骨干（如更大参数量 VLM）的扩展性验证；
  - 未报告跨具身（跨机器人形态）的泛化结果；
  - 未报告失败案例分析，难以判断失败的瓶颈环节。
- **资源信息不透明**：未说明 GPU 数量、训练时长、显存占用等关键资源指标，难以评估复现成本。
- **数据与统计局限**：
  - 真实世界试验次数较少（10–20 次），置信区间可能较宽；
  - 零样本 LIBERO-Plus 结果依赖各论文自报，协议一致性（如 rollouts 次数）未完全对齐；
  - 未提供性能方差（std/置信区间）。
- **方法潜在局限**：
  - EMA 目标依赖单视角/单步未来（t+Δ），对更长时域预测（多步自回归）的扩展未验证；
  - 动力学 token 数存在非单调效应且敏感（8 最优、16 退化），其背后的机制解释（"适度即可"）停留在推测层面；
  - 几何监督仅作用于主视角图像 token，腕部视角未被几何约束；
  - 动作条件预测依赖真值介入动作，实际部署中若中间动作偏离训练分布，预测质量可能受影响；
  - 训练目标中 λ_

- 训练目标中 λ_pred、λ_geo 均为固定经验值（0.1），未做敏感性扫描，最优权重可能随任务类型、数据规模及骨干模型变化而偏移；
- 单阶段端到端训练中 VLM 主干与新增模块采用差异化学习率，但未分析梯度交互或表征漂移对预训练知识保持的具体影响。

## 9. 总结性评价

SG-WAM 提供了一个在方法论上具有重要启示的答案：世界动作模型的有效性，既不在于未来预测的“视觉逼真度”，也不在于外部特征空间的相似性，而在于其与动作生成策略表征的“结构同源性”。通过 EMA 自引导将未来预测目标锚定在策略自身的表征坐标系中，同时借助冻结的几何基础模型注入空间结构，该方法以远小于主流 VLA 的模型规模（0.9B），在模拟基准、零样本分布偏移迁移与真实世界操作中均取得了顶尖或接近顶尖的表现。其核心贡献并非提出新颖的网络架构，而是重新回答了“未来监督应该施加在哪里”这一问题——属于概念层面的推进，对后续 WAM 设计具有直接的指导意义。

然而，该工作的验证仍集中于中低复杂度任务与单一机器人本体之上。长时域自回归预测（多步 roll-out）、多视角几何一致性的扩展、跨本体与跨形态的泛化，以及更大数据规模下的 Scaling 行为，仍是尚未回答的关键问题。表征对齐式的世界模型若要成为可扩展的通用范式，仍需要在更广的任务谱系、更长的预测视界与更多样的真实世界设定中经受检验。
