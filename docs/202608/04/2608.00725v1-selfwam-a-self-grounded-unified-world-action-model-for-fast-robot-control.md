## 摘要
世界动作模型（WAMs）通过联合建模动作和未来观察来改进机器人策略学习。然而，仅基于任务提示和观察上下文进行未来预测，可能会捕获通用的任务进展，而非所执行动作的具体后果。我们引入了SelfWAM，一种统一的自接地WAM，基于模态专用的混合变换器（MoT）架构，联合预测动作、动作条件下的未来RGB帧和机器人自掩码，从而将未来预测扎根于机器人的可见身体及其动作引发的运动。在联合训练过程中，SelfWAM允许未来视觉查询关注演示动作的干净副本，将视频分支转变为动作特定的后果模型，同时保持快速的仅动作推理路径不变。为了将视频学习聚焦于与动作相关的视觉变化，我们使用针对未来机器人自掩码预测的提示特定目标，这去除了外观细节，并提供了一个时间演化与条件动作紧密耦合的目标。共同地，干净动作条件和未来自掩码监督使未来预测更直接地反映所执行动作如何改变机器人的可见运动及周围场景。在RoboTwin 2.0和真实世界操作任务上的实验表明，SelfWAM产生了更具动作敏感性的未来，并保持了快速的策略推理，同时提高了策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

## 1. 核心问题与研究动机

- **背景**：World Action Models（WAMs）通过联合建模动作预测与未来视觉预测来提升机器人策略学习，利用预训练视频生成模型的动态先验。但现有 WAM（如 FastWAM）在预测未来视频时，仅以当前观测为条件，**并未显式使用导致该未来发生的演示动作**，因此预测出的未来只是"通用的任务进展"（generic task progression），无法区分不同动作所产生的不同视觉后果。
- **核心问题**：如何让未来预测成为**动作特定的后果建模**（action-specific consequence modeling），同时不牺牲策略推理的速度？具体表现为两个层面：
  1. 未来预测应显式条件于所执行的机器人动作；
  2. 预测目标应聚焦于与动作相关的视觉变化（尤其是机器人自身的可见运动），而非背景、纹理、光照等与动作弱相关的外观信息。
- **关键洞察**：机器人自掩码（self-mask）的未来演化与条件动作紧密耦合，可以作为一个比 RGB 更聚焦的监督信号，将未来预测"接地"（grounding）到机器人的可见身体及其动作引发的运动上。

## 2. 方法论

### 2.1 核心思想

SelfWAM 在 FastWAM 的模态专用 Mixture-of-Transformers（MoT）两流架构基础上，引入**干净动作条件路径**和**未来自掩码预测**两个新机制：

- **干净动作条件**：训练时，演示动作的**干净副本**（不加噪，t=0）经同一动作专家编码后，**仅暴露给未来视觉查询**；动作预测查询无法访问该干净副本或任何未来视觉 token。这一非对称信息流使得视频分支成为"动作-后果"模型，同时防止目标泄漏到策略分支。
- **自掩码预测**：将未来机器人自掩码序列作为第二个视觉输出域，与 RGB 预测共用同一视频骨干，通过不同输出 prompt 区分。自掩码去除外观细节，使监督信号集中于动作引起的机器人自身运动。

### 2.2 架构与信息流

- 视频流：预训练视频扩散骨干（WAN2.2-5B），处理当前观测与加噪的未来视频 latent。
- 动作流：轻量动作专家，由 WAN2.2-5B 权重插值初始化。
- 混合注意力（mixed attention）控制 token 组间信息交换，语言与本体感受特征同时条件化两条流。
- 定义 token 组：O=当前上下文，eA=加噪未来动作，A=干净动作，eV=加噪未来视觉。注意力规则为：

\[
Q_{\tilde{A}} \to \{O, \tilde{A}\}, \quad Q_{\tilde{V}} \to \{O, \tilde{V}, A\}, \quad Q_A \to \{O, A\}
\]

- 即：未来视觉查询可以关注干净动作，而动作预测查询不能看到干净动作或未来视觉 token。

### 2.3 训练目标

采用 flow-matching 损失，总目标为：

\[
\mathcal{L} = \lambda_{\text{act}} \mathcal{L}_{\text{act}} + \lambda_{\text{video}} \mathcal{L}_{\text{rgb/mask}}
\]

- 动作损失每个训练实例计算一次；
- RGB 与自掩码视频实例按 9:1 采样，自掩码实例不包含动作去噪损失；
- 实验中 λact = λvideo = 1。

### 2.4 推理模式

- **快速控制**：仅保留当前上下文编码 + 轻量动作专家，去噪 10 步预测 32 步动作块，执行前 24 步后重规划；不实例化干净动作与未来视频 token。
- **可选世界模型 rollout**：将候选动作插入干净动作路径，通过输出 prompt 选择生成未来 RGB 或自掩码视频。

## 7. 优点

1. **方法设计巧妙**：通过"干净动作副本仅暴露给视觉查询"的非对称注意力，优雅地统一了动作预测与动作条件未来建模，在不改变策略推理路径的前提下大幅增强世界模型的因果性。
2. **自掩码监督视角新颖**：将机器人自身可见运动作为预测目标，天然剔除了与动作无关的外观变量，提供了比 RGB 更聚焦的"具身"学习信号。
3. **框架通用性强**：自掩码作为视频骨干的第二个输出域（通过 prompt 切换），无需额外专家网络，结构简单且与任何视频骨干兼容。
4. **实验设计全面**：仿真+真实、多基线、消融、扰动敏感性、效率评测、路径一致性分析，证据链条较完整。
5. **保持部署高效**：训练阶段的富监督不会带来推理负担，符合机器人闭环控制的实用需求。

## 8. 不足与局限

1. **未建模接触与力**：论文自述未显式建模接触、力、遮挡交互，对接触丰富的操作任务可能不够。
2. **真实掩码依赖分割模型**：真实场景的自掩码目标依赖 RobotSeg 离线生成，分割误差可能传导到世界模型训练中；仿真中则使用精确掩码，两者存在领域差异。
3. **真实评测规模偏小**：4 个任务、每任务 10 次试验，评估统计效力有限，无法展示方法在更广真实任务上的稳定性。
4. **未来预测评测不是泛化测试**：FVD/LPIPS/PSNR 等指标衡量的是对训练集轨迹的复现匹配度，未能证明模型的可外推生成能力（如对未见场景或长时程的预测）。

6. **超参未见敏感性分析**：如 RGB:mask 采样比（9:1）、λ 权重等未做敏感性研究，最优配置的稳健性未知。
