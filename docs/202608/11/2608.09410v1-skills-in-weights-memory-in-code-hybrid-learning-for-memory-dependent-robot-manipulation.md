## 摘要
现代视觉-语言-动作（VLA）策略已获得广泛的操作技能，但通常基于当前观测或较短的固定长度历史生成每个动作块。然而，现实世界中的操作往往是非马尔可夫的，要求机器人从长时间跨度的交互历史中保留并推理任务相关信息以决定下一个动作。为应对这一挑战，我们提出HyMeS，一种混合学习框架，利用编码代理的推理与记忆管理能力来引导马尔可夫VLA执行记忆依赖的操作。具体而言，HyMeS通过基于梯度的模仿学习学习低级运动技能，同时编码代理通过启发式学习，从回滚反馈中迭代更新可执行的启发式系统，从而获得高级记忆管理策略。此外，我们通过多模态阶段完成验证来闭环引导与执行之间的循环，利用本体感觉信号和多帧VLM判断更新记忆。与端到端的记忆增强VLA相比，HyMeS仅需要针对可重用运动技能的演示，而非针对每个历史依赖的任务配置，从而实现了数据高效的组合泛化。在RoboMemArena上，HyMeS将平均累积成功率从52.5%提升至66.2%，平均任务成功率从41.3%提升至60.1%，优于pi0.5，同时在累积成功率上超过PrediMem 4.5个百分点，在任务成功率上超过14.5个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

## 1. 论文的核心问题与整体含义

- **研究背景**：现代视觉-语言-动作（VLA）模型（如 π0.5、π0.6）在各类机器人操作任务中展现出强大的低级运动技能，但它们通常只在当前观测或一段很短的历史窗口上生成动作，本质上属于“马尔可夫策略”。
- **核心问题**：真实世界的操作任务常是**非马尔可夫**的——机器人需要从长时间交互历史中记忆和推理任务相关的状态（例如最初卡片上的数字、已经完成的按压次数、目标物体的位置等），才能决定下一步动作。仅依赖当前观测会导致“观测混叠”（aliasing），即不同历史状态下当前观测相同但所需动作冲突，马尔可夫策略无法正确选择动作。
- **论文含义**：针对这一挑战，论文提出一种混合学习框架 **HyMeS**，将“运动技能”与“记忆管理策略”分离——前者留在神经网络权重中，后者以可执行代码的形式显式维护，从而在不修改策略权重的前提下，让马尔可夫 VLA 具备处理长程记忆依赖任务的能力。

## 2. 方法论

### 2.1 核心思想
- **技能在权重中（Skills in Weights）**：基础 VLA 策略通过梯度式模仿学习从演示中习得低级运动技能，权重保持不变。
- **记忆在代码中（Memory in Code）**：一个“编码代理”（coding agent）通过启发式学习（heuristic learning）在代码空间中迭代。它根据 rollout 反馈反复更新一个可执行程序 P = (C, V, U)，包含：
  - 约束选择规则 C
  - 事件验证规则 V
  - 记忆更新规则 U
- 程序 P 在运行时维护显式的符号记忆状态 `s_t`，并将其转化为可微约束（constraint reward），注入 VLA 的动作生成过程（steering），从而引导动作选择，使之与历史记忆一致。

### 2.2 关键技术细节
1. **动作生成（Motor-Skill Learning）**：使用 flow-matching 策略 πθ(a_t | o_t, ℓ)，基于演示数据 D 用 flow-matching 损失微调：
   - 插值：a_τ = (1−τ)ε + τ a，训练目标为 `∥vθ(a_τ, τ|o, ℓ) − (a−ε)∥²`。
   - 训练完成后策略参数固定，记忆学习不再修改权重。
2. **记忆状态表示**：`s_t = (plan, ρ_t, B_t, N_t, F_t)`，包括阶段计划、当前阶段、任务绑定、重复计数、持久交互状态等。
3. **可执行记忆的迭代学习**：给定候选程序 P^(n)，rollout 产生符号轨迹 ξ_n 和阶段的成功/失败标签 b_n；编码代理对比 PACE 的阶段转换与真实结果，诊断失败原因并修改程序代码，获得 P^(n+1)。评估时程序冻结，不再更新。
4. **记忆条件引导（Memory-Conditioned Steering）**：对当前阶段 ρ_t，实例化可微约束 R_ρ(a, o_t; s_t)，例如：
   - `R_reach = −∥ee(a) − Γ(target(s_t), o_t)∥²`，其中 Γ 将符号目标通过开放词汇检测与深度反投影映射为场景关键点。
   - 将该约束的梯度注入流匹配速度场：
     `v̂ = v_θ⋆(a_τ, τ|o_t, ℓ) + λ_t ∇a_τ R_ρ(a_τ, o_t; s_t)`
   - 通过 sigmoid 形式的衰减调度 λ_t 控制在接近接触区域时减弱引导，使低级策略在精细操控阶段主导动作。
5. **多模态阶段完成验证（PACE）**：
   - 采用两类证据：本体感受信号（检测运动模式、符号锁存）和多帧 VLM（Qwen3-VL-8B）判断阶段完成。
   - 每次查询产生二元判断 `d_r = e_prop ∨ e_vlm`，采用最近 w 次查询中至少 k 次通过才触发阶段切换（实验中 w=5, k=3）。
   - 该机制负责更新记忆状态并激活下一阶段的约束，形成“引导→执行→验证→更新”的闭环。

- 在相同策略权重下，HyMeS 将 RoboMemArena 上 π0.5 的 CSR 从 52.5% 提升到 66.2%，TSR 从 41.3% 提升到 60.1%。

- 消融实验表明：
  - rollout 经验使 CSR 和 TSR 分别提升 8.5 和 18.4 个百分点。

## 7. 优点

- **创新性**：将记忆管理视为“代码空间中的启发式学习”，与“权重空间中的运动技能学习”解耦，避免了对组合性记忆配置收集大量演示。
- **数据效率**：只需为复用技能收集演示，新记忆配置（不同颜色、不同计数）通过编辑代码实现，示范预算随技能数而非任务配置数缩放。
- **无需修改策略权重**：在保持 VLA 马尔可夫性质的前提下实现长程记忆能力，兼容现有预训练模型。
- **闭环机制**：PACE 的多模态验证和记忆更新实现了引导与执行的持续交互，提高了阶段转换可靠性。
- **可解释性**：显式符号记忆可审计，失败模式可分析，便于调试和改进。
- **实验结果清晰**：在模拟和真实环境中均展示了显著提升，并通过消融实验验证了各组件的必要性。

## 8. 不足与局限

- **适用范围受限**：方法依赖将任务历史压缩为紧凑符号状态，对于需要原始视觉或复杂语义记忆的任务可能不适用。
- **性能上限受限于底层策略**：即使记忆和约束正确，接触丰富的运动技能失败（如抓取偏差）仍会导致任务失败，如 Put-Back 任务所示。
- **推理开销**：周期性的 VLM 查询和编码代理调用会引入额外延迟与计算成本，不利于实时应用。
- **实验规模有限**：任务数量较少（12 个模拟 + 3 个真实），episode 数量不大，且未报告多次运行的标准差，统计稳健性不足。
- **对比公平性存在潜在偏差**：
  - PrediMem 被重新评估在修正后的任务集上，但可能不是其设计最优任务；HyMeS 的任务选择排除了“可通过观测捷径解决”或“以运动失败为主”的任务，可能偏向自身方法。
  - 真实实验中仅与 π0.5 对比，未与 PrediMem 对比。
- **VLM 在遮挡下的误判**：消融和主实验均显示视觉验证在遮挡场景中是最不可靠的，限制了该场景下的优势。
