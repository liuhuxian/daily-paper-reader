## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作(VLA)策略提出了两个关键挑战：在数据层面，高效收集高质量的全身演示需要移动基座和机械臂的协调控制；在模型层面，现有的VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为解决这些挑战，我们开发了一套全身遥操作系统和一种全景感知VLA策略。该系统通过单一VR界面实现对轮式双臂机器人的协调控制，并支持获取包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集的基础上，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。基于混合Transformer架构，PanoVLA通过专门的全景编码和融合模块引入全局空间上下文，使全景观测与语言指令和机器人状态能够有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视角基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 2. 方法论

### 2.1 全身遥操作系统

- **硬件配置**：操作员佩戴VR头显（6-DoF头部追踪）、两个手持控制器（手部姿态和夹爪指令）、三个身体追踪器（腰部+双脚踝），实现稀疏人体运动捕捉。
- **运动重建与重定向**：将稀疏追踪流实时重建为SMPL人体模型，提取骨盆运动、脚部运动和双手姿态作为重定向输入。
- **GMR重定向优化**：采用通用运动重定向（General Motion Retargeting, GMR）框架，将移动底盘建模为三维平面虚拟浮动基座，与双臂关节配置联合优化。机器人配置参数化为 q = (xb, yb, θb, qL, qR)，通过最小化加权目标函数获得全身指令：

  q∗ = argmin_q (λpos·Lpos + λrot·Lrot + λbase·Lbase + λreg·Lreg)

  其中 Lpos 对齐手部与夹爪位置，Lrot 对齐手部与末端执行器朝向，Lbase 将平面基座运动与操作员的骨盆位移和朝向耦合，Lreg 约束关节极限和配置变化。
- **模式切换策略**：提出成本驱动的模式切换机制，在自旋（spin）、阿克曼转向（ackermann）和对角平移三种运动模式间动态选择最优模式，使基座运动能灵活跟踪操作者的意图。
- **数据同步记录**：在执行过程中同步记录局部RGB视图、顶部360°全景观测、本体感知状态和全身动作。

### 2.2 PanoVLA 策略架构

- **整体架构**：PanoVLA是基于Mixture-of-Transformers（MoT）的三专家VLA策略，由VLM专家（Gemma-2B + SigLIP）、全景专家和动作专家构成。在全景专家与动作专家之间采用块状因果注意力掩码，融合接口采用Transformer KV缓存。
- **全景编码器（Panorama Encoder）**：三个关键阶段——
  - 球面投影：将同步的双鱼眼图像通过球面重投影映射为等距柱状投影（ERP）图像；
  - 全景特征提取：使用MTPano（全景基础模型），提取分割分支和深度分支的中间特征，拼接成融合的密集全景表示；
  - Token适配：通过自适应平均池化压缩为固定分辨率，再经多层感知机（MLP）映射到全景专家的隐藏维度，得到全景token序列。
- **全景专家（Panorama Expert）**：将全景token与VLM缓存进行联合自注意力，生成任务条件下的全景缓存，捕获任务相关的全局空间信息，供动作专家使用。
- **训练目标**：采用条件流匹配（Conditional Flow Matching）。给定演示动作块a、噪声样本xτ和流匹配时间步τ，最小化预测速度场与目标速度场之间的均方误差。
- **动作表示**：17维动作向量，包含双臂14维（关节+夹爪）和移动基座3维（平面速度vx、vy和偏航角速度ω）。

## 3. 实验设计

### 3.1 数据集

- 基于自建的全身遥操作系统，采集了 **800条成功遥操作轨迹**，约 **5.5小时** 多模态演示，以25Hz频率记录，共约 **50万同步帧**。
- 每个轨迹持续约20-30秒，数据记录包含：局部观测（前置+双腕部RGB）、全景观测（顶部360°相机，存储为ERP格式）、本体状态（双臂绝对关节位置、夹爪开合状态、相对起始位置的平面基座位姿）、全身动作（17维）。
- 四种任务（每次200条轨迹）：
  1. **Move Pen**：将笔放入笔架（目标方向：前/左/右）
  2. **Move Block**：将积木搬运到前方区域（左/右/双侧）
  3. **Open Curtain**：打开两侧窗帘（左/右）
  4. **Wipe Table**：擦拭长桌污渍并归还毛巾

### 3.2 基线方法

- **π0.5**：标准π0.5策略，仅使用SigLIP编码局部视角。
- **π0.5 w/ Pano**：将ERP全景直接作为额外图像输入，使用与局部视图相同的SigLIP编码器，无专门全景分支。
- **π0.5 w/ Stacked Pano**：将全景重投影为三张光轴间隔120°的透视视图后拼接为合成图像，作为额外视觉输入。
- **PanoVLA**：本文方法，使用MTPano编码+全景专家融合。

### 3.3 评估协议

- 每项任务执行15次闭环真实机器人试验，共60次试验。
- 两个指标：**成功率（SR）**——整项任务是否完整完成（二值指标）；**阶段完成率（SCR）**——所有试验中已适用阶段完成比例的平均值。

## 6. 主要结论与发现

- **全景感知显著提升移动操作性能**：PanoVLA在四项任务上平均SCR达91.3%、SR达73.4%，远优于π0.5基线（SCR 58.6%、SR 30.0%）。
- **提高阶段完成率比端到端更明显**：大SCR差距表明全景上下文对中间阶段（目标搜索、移动接近、物理操作）的提升效果显著。
- **全景的有效性依赖表示与融合方式**：直接输入ERP图像（π0.5 w/ Pano）或拼接透视视图（π0.5 w/ Stacked Pano）的提升不一致，表明仅“看得更广”不够，还需专门的几何感知编码与融合设计。
- **多阶段任务对全景融合的需求更高**：在Move Pen这类短期任务中，PanoVLA与直接全景基线持平；但在Wipe Table等多阶段任务中优势显著（SR从20%提升到46.7%），说明全景专家能更有效地跟踪任务状态转换、保持长时程空间一致性。
- **重新投影的双刃剑**：将全景转为透视视图可帮助操作密集阶段，但可能削弱跨视图连续性，在目标定位类任务上表现反而下降。
- **MTPano优于SigLIP**：全景专用编码器比通用视觉编码器更能捕捉ERP图像的水平连续性和全局布局。

## 7. 优点

- **遥操作系统的创新性**：使用GMR将移动底盘建模为虚拟浮动基座，实现自然身体运动而非操纵杆控制，解决了移动操作中“身首分离”的核心痛点。模式切换策略巧妙适配了非全向底盘的物理约束。
- **数据集的独特性**：首个同时包含360°全景观测与局部观测、本体状态、全身动作的移动双臂操作数据集，时间同步记录，可直接支持后续研究。
- **架构设计的针对性**：分工明确的三专家架构——VLM负责语义理解、全景专家负责全局空间、动作专家负责动作生成，通过KV缓存机制实现轻量高效的多模态融合。
- **全景编码的合理性**：利用MTPano同时捕捉语义和几何信息，通过球面投影处理ERP图像畸变问题，解决了“全景图像与预训练视觉编码器域差距”的关键难点。
- **实验设计的严谨性**：引入了三个层次丰富的基线（无全景、原始全景、堆叠全景），能够准确归因性能提升来源。
- **无需大规模重训练**：在冻结语言模型和MTPano的情况下，仅微调其余模块即可获得显著性能提升，具有良好的数据效率。

## 8. 不足与局限

- **实验规模与统计可靠性**：每任务仅15次试次，样本量偏小，缺乏方差估计和显著性检验，结论的统计稳健性存疑。
- **消融实验覆盖不全**：全部消融只在Move Pen单任务上进行，该任务本身是短期任务，无法反映各种设计选择在多阶段、长时程任务中的表现。
- **基线对比范围有限**：仅与π0.5同源基线对比，未与MoManipVLA、AC-DiT、SG-VLA等现有移动操作方法进行比较，难以定位PanoVLA在整体技术生态中的相对水平。
- **任务泛化性受限**：任务集中于室内桌面级操作，场景布局相对简单，目标种类有限；未涉及更复杂的室外环境、动态障碍物、多房间导航等场景。
- **数据采集效率瓶颈**：虽然遥操作系统降低了操作员负担，但VR设备+身体追踪器的部署成本较高；800条轨迹（5.5小时）的数据规模相对有限，可能限制模型的泛化能力。
- **全景专家参数规模的敏感性**：实验显示50M专家容量不足、300M专家有限数据下反而下降，说明对训练数据量较为敏感，规模化策略有待进一步研究。
- **训练细节报告不完整**：未披露训练总耗时、单次试验推理延迟、模型收敛性等信息，复现门槛较高。
