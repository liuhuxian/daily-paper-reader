## 摘要
长时程手术机器人操作具有挑战性，因为任务奖励稀疏，而有意义的交互变化以不规则的间隔发生。现有的世界模型智能体通常以原始动作步长分辨率进行想象，使得可变持续时间的任务进展隐含其中。手动指定的阶段可以提供中间结构，但其任务特定的边界难以与依赖于状态的交互转换对齐。我们提出了S2-HWM，一种稀疏事件结构化的层次世界模型，它从原始潜在轨迹中学习稀疏事件证据，以协调事件级管理器和原始步长工人。事件证据调度管理器目标更新，每个选中的潜在目标条件化工人的原始动作，直到下一次更新。学习到的事件证据还形成了事件转换模型（ETM）的可变持续时间段，该模型预测下一个边界随机状态、段持续时间和累积段奖励。将这些事件级预测链接起来，为管理器学习提供了超出原始想象视野的可变持续时间延续，而工人则保留原始步长的演员-评论家学习。在基于SurRoL的PegTransfer任务中，S2-HWM达到了98.7%的成功率，比扁平的GAS DreamerV3基线高出22.7个百分点。

## Abstract
Long-horizon surgical robot manipulation is challenging because task rewards are sparse, while meaningful interaction changes occur at irregular intervals. Existing world-model agents typically imagine at primitive-step resolution, leaving variable-duration task progress implicit. Manually specified stages can provide intermediate structure, but their task specific boundaries are difficult to align with state-dependent interaction transitions. We propose S2-HWM, a Sparse Event-Structured Hierarchical World Model that learns sparse event evidence from primitive latent trajectories to coordinate an event-level manager and a primitive-step worker. The event evidence schedules manager goal updates, and each selected latent goal conditions the worker's primitive actions until the next update. The learned event evidence also forms variable-duration segments for an Event Transition Model (ETM), which predicts the next?boundary stochastic state, segment duration, and accumulated segment reward. Chaining these event-level predictions provides a variable-duration continuation beyond the primitive imagination horizon for manager learning, while the worker retains primitive-step actor-critic learning. On a SurRoL-based PegTransfer task, S2-HWM achieves a success rate of 98.7%, outperforming the flat GAS DreamerV3 baseline by 22.7 percentage points.

- **论文的核心主张**：应从交互动力学中**学习**事件边界，而非依赖人工指定，并通过事件结构将原始步长控制与事件级决策有机结合，从而解决长时程稀疏奖励下的策略学习问题。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 总体框架

S²-HWM 构建了一个**双时间尺度层次世界模型**，包含两个核心层级：

- **事件级管理器（Manager）**：在稀疏的事件边界处选择潜在目标（latent goal），用于高层决策。
- **原始步工人（Worker）**：在管理器目标的条件化下，以原始步长执行具体动作。

### 2.2 关键组件与流程

- **原始世界模型（Primitive World Model）**：采用 DreamerV3 的循环状态空间模型（RSSM），更新潜在特征 `ft = [zt, ht, mt]`，其中 `zt` 为随机状态、`ht` 为确定性循环记忆、`mt` 为持久化交互上下文。
- **稀疏上下文动力学与事件边界**：
  - 引入一个上下文模型 `Φ_ctx`，从 `(z_{t-1}, a_{t-1}, m_{t-1})` 预测候选上下文更新 `m̃_t` 和软门控 `ρ_t`。
  - 通过直通估计器（straight-through）二值化产生**稀疏事件证据** `g_t = ST(ρ_t)`。
  - 对同一事件证据施加不同的接受规则（acceptance rules），分别用于管理器更新调度和ETM训练段构建。
- **事件对齐的分层策略**：
  - 在管理器更新点 τᵢ，管理器从边界特征 `Fᵢ = f_{τᵢ}` 采样离散码 `cᵢ`，经学习码本 E 映射为潜在目标 `ηᵢ`，该目标在下一个更新点之前持续条件化工人动作。
- **事件转移模型（ETM）**：
  - 基于相邻接受边界构建可变时长分段 `eᵢ = [τᵢ, τᵢ₊₁)`，ETM 以起始边界事件状态 `x_{eᵢ} = [z_{τᵢ}, m_{τᵢ}]` 为输入，预测下一个边界随机状态、分段时长和累积分段奖励。
  - 引入内部分类转移模式 `uᵢ`（区分于管理器码 `cᵢ`）来建模同一个起始状态下不同后续结果的变异性，训练时使用后验推断、想象时使用先验预测的最可能模式。
- **事件扩展的管理器自举（Bootstrap）**：
  - 管理器价值目标由短视原始步想象估计 `B_short` 和事件级延续 `B_event` 加权组合：`B_M = (1-ω)B_short + ωB_event`。
  - 事件级延续通过 K 次递归 ETM 转移（预测边界状态、时长、奖励，并使用时长相关折扣 γ^Δ）实现，无需递归预测每个中间原始状态，从而减少误差累积。

## 6. 论文的主要结论与发现

- **核心结果**：S²-HWM 在单次转移任务中达到 98.7%±2.3% 成功率，比 GAS-DreamerV3 的 76.0%±12.0% 高出 **22.7个百分点**；PPO和DreamerV2在预算内无法学会任务。
- **层次策略是最大贡献者**：移除层次策略（用平铺actor替代）导致最大性能退化（降至68.0%），说明事件证据必须通过管理器转化为持续性潜在目标并由工人执行才能发挥作用。
- **事件对齐更新优于固定周期更新**：固定 K=15 更新相比事件对齐更新显著降低性能（80.7% vs. 98.7%）且方差大幅增大，表明自适应事件边界对跟踪不同交互阶段（接近、抓取、搬运、放置）的时长变化至关重要。
- **ETM的贡献**：单次转移中移除ETM仅降低7.4个百分点，但在重复转移和扰动测试中差距扩大至16.6和20.7个百分点——任务越需要长时程规划，事件级延续的价值越显著。
- **机制验证**：ETM多事件预测误差增长慢于策略条件的RSSM滚动；管理器码与结构化工人行为存在关联（如抓取阶段垂直调整和夹爪动作突出、放置阶段横向修正突出），且这种结构完全来自学习而非语义标签监督。

## 7. 优点

- **创新性**：将事件边界学习与层次世界模型结合，用同一事件证据同时驱动管理器调度和ETM训练，是一个简洁而统一的设计思想。
- **方法严谨性**：
  - 避免了人工阶段标注，从交互动力学中自适应发现事件边界，解决了固定阶段边界与实际交互状态不对齐的问题。
  - ETM跳过中间状态直接预测边界结果，有效限制了长时程预测中的误差累积（对应图示量化评估显示其误差增长更慢）。
  - 双时间尺度想象（短视原始步 + 事件级延续）的设计兼顾了局部动力学精度和全局任务覆盖。
- **实验设计**：消融与压力测试逐层剥离组件贡献；诊断性分析（预测误差、策略-行为关联）补充验证了内部机制的有效性。
- **应用价值**：为长时程手术操作提供了一种不依赖人工标注的层次强化学习新范式，尤其是在计算精度要求高且交互不确定的临床模拟场景中。
