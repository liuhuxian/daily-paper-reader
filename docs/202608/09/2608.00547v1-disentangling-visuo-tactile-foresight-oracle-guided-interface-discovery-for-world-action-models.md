## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于通常仅从视觉中难以观察到的物理交互线索。最近提出的触觉世界行动模型联合建模未来的视觉观测和触觉信号以指导动作生成，但如何为行动专家有效使用这些未来信息构建结构仍未被充分探索。直接用学习到的世界行动模型研究这一问题是很困难的，因为端到端行为将物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测，以及不可读的未来到动作接口纠缠在一起。为了使这一接口可独立研究，我们引入了Oracle视觉-触觉预见（OVTF），这是一个受控框架，提供来自模拟中验证成功的轨迹的配对RGB和触觉未来。通过固定未来提供者，OVTF隔离了接口，并提出一个更清晰的问题：如果未来是成功的且物理上可执行的，什么表示能让行动专家吸收其益处？在OVTF内，我们提出了非对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆联合关注其自身的触觉流和相位对齐的未来视觉，并阻断跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者移除视觉到触觉的访问，并独立处理每种未来模态。在UniVTAC模拟基准的七个任务中，AFM实现了32.0%的平均成功率，而IFM为23.7%，UniVTAC-ACT为14.9%。这一受控比较表明，选择性的相位对齐视觉-触觉路由比完全模态隔离提供了更可操作的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

## 1. 核心问题与整体含义（研究动机与背景）

- 接触丰富的机器人操作（contact-rich manipulation）高度依赖物理交互线索（如力、触觉、接触形变），这些线索往往难以仅从视觉观测中充分获取。
- 现有触觉世界行动模型（tactile world action models, WAMs）通过联合建模未来视觉观测与触觉信号来指导动作生成，但**"未来信息应如何结构化并传递给行动专家"**这一核心问题尚未被充分探索。
- 直接以端到端学习的方式研究该问题面临四个纠缠因素：
  1. 物理上无效的视觉未来（违反接触力学的不可执行轨迹）；
  2. 对未来分支的信任不足（预测不稳定导致行动分支学会忽略未来信息）；
  3. 错误或跨模态不一致的触觉未来（接触时序、形变等难以精确预测）；
  4. 不佳的未来到动作接口（即使未来正确，行动分支也无法有效读取）。
- 这四类效应在最终任务得分中互相纠缠，**无法单独度量"接口"本身的质量**。为此，论文提出 **OVTF（Oracle Visuo-Tactile Foresight）** 框架，用模拟中已验证成功的轨迹作为固定的"未来提供者"，将未来提供端的误差剥离，从而独立研究**未来→动作接口**的设计问题。

## 2. 方法论：核心思想与技术细节

### 2.1 OVTF 框架（Oracle Visuo-Tactile Foresight）

- **未来来源**：从成功演示轨迹（HDF格式）中采样当前初始条件下的未来帧，提供成对的视觉（RGB）与左右触觉图像序列。采样长度至多 N=100 帧。
- **相位定义**（公式1）：

  ```
  φi = (τi − τref) / max(1, T − 1 − τref)，φi ∈ [0,1]
  ```

  表示第 i 帧相对于参考索引的"剩余水平阶段"（0表示现在，1表示轨迹终点）。
- **关键约束**：Oracle只提供未来视觉与触觉RGB图像，**不提供未来动作、未来qpos、物体位姿、模拟器状态、成功标签等特权元数据**——因此它只是一个"受控诊断性未来源"，而非可泛化的学习型预测器。
- **编码器**：未来视觉与触觉帧分别用可训练的ResNet-18编码，初始化自 UniVTAC-ACT\* 的当前观测编码器权重，输出三个序列 H, L, R ∈ ℝ^{N×512}（分别对应视觉、左触觉、右触觉）。

### 2.2 门控局部时间残差

- 每个模态序列经过一个门控深度卷积模块（depthwise Conv1d, kernel=5）：

  ```
  X′_m = X_m + tanh(g_m) · Conv_DW(LN(X_m))
  ```

- 三个门控参数 g_m 初始化为零，使得新引入的未来残差在初始化时被完全抑制，保持与预训练模型的兼容性。

### 2.3 AFM（Asymmetric Phase-Local Future Memory，非对称相位局部未来记忆）

- **结构**：12个可学习的512维slot：4个视觉槽、4个左触觉槽、4个右触觉槽。
- **相位锚点**：C = {0.125, 0.375, 0.625, 0.875}，将未来流划分为四个局部时间阶段。
- **注意力分数**（公式6）：结合内容注意力与高斯相位先验：

  ```
  score = (q^T k) / √64 − (φi − ck)² / (2 × 0.18²)
  ```

  高斯项是软相位先验而非硬时间窗口，内容注意力仍可在全部有效位置中选择。
- **路由模式**（AFM，公式9）：

  ```
  H ← H；L ← (L, H)；R ← (R, H)
  ```

  即：视觉记忆只读未来视觉；每个触觉记忆联合关注"自身触觉流 + 相位对齐的未来视觉"；**左右触觉之间禁止互相访问**。
- 每个触觉槽对"触觉序列+视觉序列"的拼接执行**单一联合多头注意力**，而非先读触觉再读视觉的两阶段操作。

### 2.4 IFM（Modality-Isolated Future Memory，模态隔离未来记忆）

- 对照条件，路由模式（公式10）：

  ```
  H ← H；L ← L；R ← R
  ```

- 与AFM的唯一差异是移除 H→L 和 H→R 的可读边；其余全部相同（未来提供者、相位锚点、记忆预算、优化设定）。

### 2.5 ACT 策略集成

- 当前视觉/触觉观测由**冻结的** UniVTAC-ACT\* 编码器处理，qpos 经冻结的状态投影得到当前空间记忆。
- 每个未来槽乘以一个零初始化的 tanh 门控后进入 ACT 编码器记忆。
- 编码器记忆组织：`[z0 + s1, q, s2, ..., s12, M_current]`
- 解码器：50个动作查询，输出 50×8 的动作块；评估时按年龄权重 exp(−0.01×age) 聚合重叠动作块。
- AFM 禁用 CVAE/动作编码器，潜在变量 z 恒为零。
- 训练目标：掩码动作 L1 损失，slot 去相关仅作为 detached 的非反向传播正则。

## 6. 主要结论与发现

### 6.1 核心结果

| 条件 | 平均成功率 |
|------|-----------|
| UniVTAC-ACT\* | 14.9%（52/350） |
| AFM Zero-Train | 20.0%（70/350） |
| AFM Forced-Zero | 19.4%（68/350） |
| **IFM** | 23.7%（83/350） |
| **AFM Oracle** | **32.0%（112/350）** |

### 6.2 关键发现

1. **选择性相位对齐的视觉→触觉路由比完全模态隔离更可操作**：AFM Oracle 比 IFM 高 8.3 个百分点。即使用户态模态标记在后续ACT编码器中仍可重新交互，接口处的显式非对称融合仍能提供下游自注意力无法恢复的信息组织优势。
2. **Oracle训练的策略确实使用了测试时的未来内容**：Forced-Zero 将成功率从32.0%降至19.4%，证明提升并非仅来自额外模块的参数容量。
3. **AFM兼容的纯当前观测策略路径也强于基线**：Zero-Train 达20.0%，无未来信息时仍高于 UniVTAC-ACT\* 的14.9%。
4. **任务层面的差异**：
   - Put Shelf（54%）和 Pull Out Key（54%）展示出未来信息最清晰的行为价值；
   - Insert Tube 中 Oracle 与 Forced-Zero 并列42%，说明策略提升在无未来信息时也能持续；
   - Insert Hole 是唯一 IFM 最高（8%）的任务，但所有条件均接近成功率地板。

## 7. 优点

- **问题解缠思路新颖**：OVTF 将未来提供者（预测质量）与未来→动作接口（消费质量）成功解耦，使得接口设计可以被独立、干净地度量——这是对现有端到端WAM评估方式的实质性改进。
- **控制变量设计严谨**：AFM 与 IFM 之间仅有一条路由规则之差；Oracle/Zero-Train/Forced-Zero 三种条件形成完整的"未来信息有无/是否实际使用"对照控制，因果归因清晰。
- **接口设计有洞察力**：非对称相位对齐的视觉→触觉路由符合物理直觉——触觉信号需要视觉上下文来解释接触情境，但左右触觉之间可能没有直接跨模态依赖。该发现在对比实验中获得了数据支持。
- **初始化稳定性设计**：门控零初始化（tanh gate）和深度卷积残差的零门控确保新模块加入时不影响预训练行为。

## 9. 未解问题与未来方向

1. **可学习未来预测器的联合训练**：OVTF 将未来提供端完全抽象为 Oracle，下一步自然且关键的方向是将接口设计原则（相位对齐的视觉→触觉非对称路由）与可学习的未来预测器联合训练，使预测器在训练中适应接口的读取偏好。
2. **自适应路由机制**：AFM 的路由模式是手工固定的（视觉→左/右触觉，左右隔离）。当任务要求左右手协同接触（如双手装配）时，左右触觉之间的依赖便不可忽略。未来可探索基于任务或基于上下文动态学习路由权重（如 soft gating）的机制。
3. **更细粒度的相位表征**：当前相位仅由轨迹索引线性映射得到，不支持复杂时序结构（如等待、重复运动、多阶段接触）。可考虑用学习式相位编码或分段式时序表征替代固定线性相位。
4. **真实机器人验证**：模拟环境中的成功率提升需要在真实机器人平台上复现，特别是在触觉传感器噪声、视觉遮挡与校准误差等实际条件下检验接口设计的鲁棒性。
5. **多模态扩展**：除视觉与双触觉外，力/力矩传感器、本体感觉、音频等模态同样承载交互信息。接口框架可扩展为更一般化的跨模态记忆路由问题，而不仅限于视觉-触觉二元组合。

---

## 10. 个人评价与综合判断

**总体判断**：这是一篇问题意识清晰、方法设计精巧、实验控制严谨的优秀研究工作。它没有试图在端到端 WAM 的完整链路上做“全能式”改进，而是精准地切中了“未来→动作接口”这一长期被忽视的环节，用 Oracle 手段将其与其他混淆因素解离开来，从而产出了可独立验证的接口设计结论。这种“解缠-诊断-归因”的研究范式在机器人学习领域具有方法论价值。

**最核心的学术贡献**可以概括为两点：其一，首次将 WAM 中“未来信息如何结构化并传递给动作专家”的问题从端到端黑箱中独立出来，并提供了可行的实验范式；其二，通过严格的对照实验揭示了“非对称相位对齐的视觉→触觉路由优于模态隔离路由”这一具体且可操作的接口设计原则。这一发现也兼具物理直观性与可迁移性——触觉信号需要视觉上下文来解释“为什么接触”“接触什么”，而左右触觉之间则不存在类似依赖。

**研究定位**：OVTF 更适合被理解为一种**接口设计探针**而非完整解决方案。它对接口设计的结论是相对可信的，但所有结论都建立在“完美未来”的前提之上。如何将接口设计原则转化为实际可训练的未来预测器与策略的联合优化，是后续工作中必须跨越的鸿沟。

---

## 11. 结论（一句话总结）

本文通过 Oracle 引导的解缠框架 OVTF，将未来预测质量与未来→动作接口质量分开度量，并借助严格受控的对照实验证明：接触丰富的机器人操作中，按相位对齐的非对称视觉→触觉路由（AFM）作为未来到动作的接口，优于完全模态隔离路由（IFM），且其收益确实来自对测试时未来信息的实际利用，而非单纯的模块容量增加。
