## 摘要
模仿学习（IL）——通过演示训练智能体复制专家行为——支撑着从机器人技术到语言模型训练的各种应用。已知标准方法如行为克隆（BC）会遭受复合误差和性能平台期，特别是当学习者无法完美表征专家策略时（例如在蒸馏中很常见）。经验上广泛认为有两种干预措施可以提升性能：在学习者自身轨迹上交互式地查询专家，以及在生成策略过程中使用价值函数估计，而不是直接拟合专家的完整动作分布。我们研究了这些改进的性质及其可能令人惊讶的相互作用。我们的主要发现是，专家交互放宽了学习者的表征要求：只需要一个能够实现专家价值函数的模型，而绕过了实现专家策略本身（通常更严格）的要求。具体来说，我们引入了OVI，一种交互式在线策略IL算法，只要学习者能够表征专家价值函数，它在统计上就是高效的，并且在给定线性最大化预言机的情况下计算上也是高效的。我们用一个负面结果补充了这一点，表明交互是必要的。也就是说，在没有超越专家价值可实现性的更强假设下，任何离线IL算法都必须随专家策略类的复杂度而扩展。我们的发现得到了实证验证。OVI优于基于离线策略（BC）、交互式策略（DAgger）和基于离线价值的IL方法，当学习者网络的表现力远低于专家时，收益最大。

## Abstract
Imitation learning (IL)---training an agent to replicate expert behavior from demonstrations---underpins applications from robotics to language model training. Standard approaches such as Behavior Cloning (BC) are known to suffer from compounding errors and performance plateaus, particularly when the learner cannot perfectly represent the expert's policy (as is typical, e.g., in distillation). Two interventions are widely understood empirically to improve performance: querying the expert interactively along the learner's own trajectories, and using value function estimation en route to generating a policy rather than directly fitting the expert's full action distribution.   We investigate the nature of these improvements and their potentially surprising interplay. Our main finding is that expert interaction relaxes the representational demands on the learner: one only needs a model capable of realizing the expert's value function, bypassing the (often stricter) requirement of realizing the expert's policy itself. Concretely, we introduce OVI, an interactive on-policy IL algorithm that is statistically efficient whenever the learner can represent the expert's value function and computationally efficient given access to a linear maximization oracle. We complement this with a negative result showing that interaction is necessary. Namely, without stronger assumptions beyond expert-value realizability alone, any offline IL algorithm must scale with the complexity of the expert policy class. Our findings bear out empirically. OVI outperforms offline policy-based (BC), interactive policy-based (DAgger), and offline value-based IL methods, with the largest gains when the learner network is substantially less expressive than the expert's.

## 1. 论文的核心问题与整体含义

模仿学习（Imitation Learning, IL）旨在通过专家演示训练智能体复制专家行为，其应用涵盖机器人控制与语言模型训练等关键领域。然而，最主流的方法——行为克隆（Behavior Cloning, BC）——在实际中面临两大困境：**复合误差（compounding errors）**和**性能平台期**，尤其是在学习者无法精确表征专家策略时（如模型蒸馏中学生模型远小于教师模型）。经验上有两种被广泛认可的干预措施：

1. **在线策略交互（on-policy interaction）**：在学习者自身轨迹上向专家查询动作。
2. **基于价值的模仿学习（value-based IL）**：借助学习到的价值或奖励函数来生成策略，而非直接拟合专家的完整动作分布。

本论文的核心问题在于：**这两种干预措施各自的作用机制是什么？它们之间是否存在意想不到的相互作用？**

作者给出了一个关键答案：**专家交互可以显著放松学习者的表征需求**。具体而言，在线交互式模仿学习只需要学习者能够实现专家的价值函数（$Q^{\pi_E}$-realizability），而无需实现专家策略本身——后者往往是更严格的要求。这一发现不仅从理论上澄清了交互的价值（不再仅限于经典的"改善horizon依赖"），也为实践中的蒸馏和模仿学习提供了新的设计方向。

## 2. 论文提出的方法论

### 2.1 核心思想：交互如何放松表征需求

传统策略类方法（BC、DAgger）要求策略类 $\Pi$ 满足**策略可实现性**（policy realizability），即 $\pi_E \in \Pi$。而本文提出的价值类方法只需满足**专家价值可实现性**（$Q^{\pi_E}$-realizability），即价值函数类 $\mathcal{Q}$ 只需包含专家价值函数 $Q^{\pi_E}$。

论文通过两个示例说明了 $Q^{\pi_E}$-realizability 为何弱于 policy realizability：

- **示例 3.1**：给定有限策略类 $\Pi$ 实现最优专家，可构造相同量级的 $\mathcal{Q}$ 实现专家价值函数，但反之不成立。
- **示例 3.2**：在外生噪声环境（ExBMDP）中，专家策略需要依赖高维观测中的解码器，而价值函数只依赖低维内生状态，$Q^{\pi_E}$ 的复杂度可以远低于 $\pi_E$。
- **定理 3.2**：仅奖励可实现性（reward realizability）在海平面 $H>1$ 时不足以实现高效 IL，因此 $Q^{\pi_E}$-realizability 是自然的最小假设。

### 2.2 OVI 算法

OVI（On-Policy Value-Based Imitation Learning）将累计奖励差距分解为逐层的鞍点问题。以性能差异引理为起点：

$$J^{\pi_E} - J^{\pi} = \sum_{h=1}^{H} L^{d^{\pi}_h}(\pi_h, Q^{\pi_E}_h)$$

OVI 通过逐层（layer-wise）方式进行学习：

- **外层循环** $h=1,\dots,H$：在阶段 $h$ 采样 $x_h \sim d^{\pi_{\text{out}}}_h$，并查询专家动作 $a_{E,h} \sim \pi_{E,h}(\cdot|x_h)$。
- **内层循环** $k=1,\dots,K$：
  - **Q-player**：对经验目标做最优响应，即在 $\mathcal{Q}_h$ 中选最大化经验损失的 $Q^k_h$（线性最大化预言机）。
  - **π-player**：用 softmax 策略更新（指数权重上升法）：
    $$\pi^{k+1}_h(a|x) \propto \pi^k_h(a|x) e^{\eta Q^k_h(x,a)}$$
- 最终输出 $\pi_{\text{out},h} = \frac{1}{K}\sum_{k=1}^{K}\pi^k_h$。

这种逐层学习的设计保证了采样分布 $d^{\pi_{\text{out}}}_h$ 在第 $h$ 阶段只依赖前 $h-1$ 层的策略，从而使得无遗憾在线学习成为可能。

### 2.3 理论保证

- **定理 3.1（样本复杂度）**：在有限类别 $\mathcal{Q}$ 满足 $Q^{\pi_E}$-realizability 下，OVI 的专家查询复杂度为：
  $$\tilde{O}\left(\frac{H^5 Q_{\max}^4 \log(A)\log(|\mathcal{Q}|/\delta)}{\varepsilon^4}\right)$$
  该复杂度仅由 $\mathcal{Q}$ 的统计容量控制，不依赖于策略类。
- **定理 4.1（离线下界）**：仅凭 $Q^{\pi_E}$-realizability，任何离线 IL 算法都需要 $\Omega(|\mathcal{X}|/\varepsilon)$ 条专家轨迹。
- **定理 4.2（非可辨识性）**：输出"价值诱导策略"的离线算法（如 SPOIL、IQ-Learn 等）即使数据无限，也会产生常数下界误差。
- **变体 Q-OVI**（附录 H）：Q-player 先做在线学习，π-player 贪心最佳响应，获得 $\tilde{O}(\varepsilon^{-2})$ 的更好统计速率，但需要离散化价值函数类，计算效率低。

## 6. 论文的主要结论与发现

1. **交互放松表征需求**：在线策略交互使得仅需 $Q^{\pi_E}$-realizability 即可实现高效模仿学习，绕过了实现专家策略本身的严格要求。
2. **交互是必要的**：在只有 $Q^{\pi_E}$-realizability 的情况下，任何离线 IL 算法都必须付出与状态数量或策略类复杂度相当的代价。
3. **价值诱导策略的离线不可辨识性**：即使数据无限，离线算法若只输出基于价值函数的策略，也会因"价值等价但行为不同"而失败。
4. **OVI 的实证优势**：在表达能力差距大时，OVI 优于 BC、DAgger 和 SPOIL，验证了理论预测。
5. **链式思维学习的计算优势**（第 5 节）：OVI 可用于链式思维（CoT）学习，将响应空间的指数级搜索分解为逐 token 的局部策略更新，将非交互式方法（如 Joshi et al., 2026）的指数计算成本转化为多项式成本，为过程奖励模型（process reward models）和在线蒸馏提供了理论支持。

## 7. 优点

1. **理论贡献扎实**：完整的"上界+下界"结构——正面结果（OVI 的样本复杂度）与负面结果（离线不可行、奖励可实现不足）相互配合，清晰刻画了"交互 × 价值表征"的作用机制。
2. **算法设计巧妙**：OVI 的逐层学习设计解决了以往基于博弈的方法（如 Moulin et al., 2025a 的 SPOIL）在 $Q^{\pi_E}$-realizability 下无法同时控制采样分布和估计误差的问题。
3. **计算效率良好**：OVI 只需要线性最大化预言机 + softmax 策略更新，可直接用神经网络实现（实验中使用了 SoftDQN 近似），与目前深度学习实践高度兼容。
4. **实证支持充分**：实验结果与理论预测一致，特别是在表达能力差距最大的情况下 OVI 优势最大。
5. **对 LLM 蒸馏有启示**：链接到在线蒸馏和过程奖励模型，为当前语言模型训练提供了新的理论视角。

## 8. 不足与局限

1. **统计效率非最优**：OVI 对非凸类 $\mathcal{Q}$ 的样本复杂度含 $\tilde{O}(\varepsilon^{-4})$ 因子，而 Q-OVI 虽可改进到 $\tilde{O}(\varepsilon^{-2})$，但需要离散化价值类，计算上不适用于大参数模型。这一"计算-统计"权衡留待未来解决。
2. **非平稳策略限制**：OVI 输出的是逐层非平稳策略，需要与 horizon 线性相关的存储和计算成本。论文虽验证了平稳近似（Algorithm 2）在实践中有效，但理论上能否计算平稳策略尚未解决。
3. **实验规模有限**：实验仅在小型 Gymnasium 控制环境上进行，没有验证大规模场景（如机器人操作、语言模型蒸馏）中的效果。作者本人也在结论中指出"将 OVI 应用于语言模型蒸馏仍是一个重要的实证方向"。
4. **实例依赖性**：不同环境中方法间的差距不一致（如在 Pendulum 和 LunarLander 中，DAgger 与 OVI 差距较小），表明问题实例的特征会影响交互和价值表征的相对重要性，论文缺乏对这种现象的理论解释。
5. **未处理价值函数误设（misspecification）**：论文假设 $Q^{\pi_E} \in \mathcal{Q}$ 严格成立。如果价值类存在近似误差，当前理论无法提供保障，而这也是实践中很可能发生的情况。
6. **交互成本的模型限制**：论文的交互协议假设专家可随时在学习者访问的状态下提供标注，但在实际应用中（如人类专家标注）这可能成本高昂或不现实。
