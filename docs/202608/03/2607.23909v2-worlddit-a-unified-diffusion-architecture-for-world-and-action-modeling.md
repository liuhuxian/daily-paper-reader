## 摘要
许多最近的机器人策略通过使用大型预训练视觉-语言模型（VLM）作为动作主干来追求更强的控制能力。我们引入了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相结合，并在无需大型预训练VLM动作主干的情况下实现了强劲的性能。在训练过程中，一个单一的扩散Transformer生成连续的动作块，并从未来的相机帧中预测归一化的RGB补丁目标。在四个LIBERO模拟套件中，WorldDiT处于报告所有四个套件的方法中关于总模型参数和平均成功率的报告帕累托前沿上。这些结果为未来的扩展研究提供了一个强大的亚十亿参数基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
- 提出 **WorldDiT**，一个统一的扩散Transformer（DiT）骨干架构，同时完成两件事：
  1. **连续动作块生成**（动作路径）
  2. **未来归一化RGB块预测**（世界模型路径，仅训练时使用）
- 关键设计原则：**单一共享骨干**承担动作和视觉两种目标，而非依赖大型VLM的自回归生成。

### 2.2 输入表示与多模态编码
- 观测窗口：一段 N 步轨迹，含主相机图像、腕相机图像、机器人状态、语言指令。
- **上下文**：C = 3 步观测历史（前3步），用于条件化。
- **动作目标**：H = 7 步动作块，A ∈ ℝ^(7×7)。
- **未来世界目标**：从第 i+H 帧的主相机与腕相机图像中，每个 224×224 CLIP预处理图像划分为 16×16 块，每块取 768 维向量，经归一化后每相机均匀保留 64 个块，拼接得到 128×768 的未来RGB块目标。
- **编码器**：冻结的MAE图像编码器 + 共享Perceiver Resampler、冻结CLIP文本编码器、可训练机器人状态编码器（手臂和夹爪分别编码后拼接投影）。

### 2.3 训练（Flow Matching）
- 采用 **flow matching** 目标：对动作目标和未来RGB块目标，从高斯噪声到干净目标插值直线路径，回归目标速度。
- 噪声化过程：x_τ = (1-τ)ε + τy，其中 τ ~ U[0,1]。
- 损失函数：
  - L_flow = E[‖v_θ(x_τ, τ, c) − (y − ε)‖²]
  - 总损失 = w_action · L_action_flow + w_rgb · L_rgb_flow
  - 权重：w_action = 0.1，w_rgb = 0.001
- 仅最终时间槽（final temporal slot）参与RGB损失。
- 骨干为深度4、隐藏大小1024、16注意力头、4个register tokens的DiT。

### 2.4 推理
- 推理时**仅走动作路径**，RGB块预测头完全不在推理图中。
- 从高斯噪声初始化动作块，使用20步欧拉积分求解速度场（τ从0到1）。
- 预测7个动作，**执行前3个**，更新窗口后重新规划（receding-horizon control）。
- 使用预测动作的**时间集成（temporal ensembling）**对重叠的绝对时间动作预测进行聚合。

## 7. 优点（方法或实验设计亮点）

- **架构统一性**：单一共享DiT骨干同时处理动作生成与未来视觉预测，不需大型VLM骨干，体现了简洁高效的设计哲学。
- **世界模型路径语义清晰**：未来RGB块预测提供辅助监督但**推理时完全移除**，保持了部署路径的轻量性。
- **可复现的损失设计**：动作与视觉目标共享同一flow matching公式，权重明确（0.1与0.001），结构简洁。
- **诚实严谨的报告态度**：主动声明评估中非完全无关的episode选取问题，并明确标注比较方法分数未经统一协议复现，这在学术论文中较为少见。
- **亚十亿参数基线**：为未来扩展研究提供了清晰的计算成本与性能参照点。
- **未来方向的启示**：因动作与视觉共享flow matching公式，可自然支持分解为独立训练的专家模型（如Paris、Paris 2.0方向），适用于异构硬件与计算受限平台。
