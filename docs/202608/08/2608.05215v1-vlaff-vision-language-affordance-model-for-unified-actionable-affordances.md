## 摘要
从人类视频中学习操作技能对于可扩展的机器人学习具有前景。然而，人类与机器人之间的本体差异使得这一任务具有挑战性。一个可行的解决方案是学习与本体无关的、以物体为中心的可操作可供性。在本工作中，我们提出一个框架，利用自我中心人类视频结合先进的3D运动恢复结构和手部网格重建，提取可操作可供性，如视觉可供性、抓取可供性和轨迹可供性，这些可供性明确编码了在哪里交互、如何抓取以及如何移动。我们构建了EgoAffordance，这是一个大规模数据集，包含204K个片段，具有560万视觉可供性和1160万抓取及轨迹可供性。在此基础上，我们引入VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可操作可供性之间的跨模态相关性。给定视觉观察和指令，VLAff生成视觉可供性热图、抓取姿态和轨迹，然后利用3D场景信息将这些转换为可直接执行的动作。通过大量实验，我们证明VLAff不仅在视觉可供性预测上达到了最先进的性能，而且可以有效地应用于实际机器人应用，如零样本操作和可供性引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

- **核心问题**：如何从大规模人类视频中高效学习可迁移的机器人操作技能，同时克服**人类与机器人之间的本体（embodiment）差异**。
- **研究动机**：

  - 互联网规模的人类视频易于获取，但直接使用存在两个障碍：本体形态差异，以及视频缺乏显式动作-状态信息。
  - 现有基于可供性（affordance）的研究要么只关注单一模态（如仅有视觉热图、抓取或轨迹），要么局限在 2D 图像空间，缺少一个统一的、可操作的、与本体无关的中间表示。
- **整体含义**：提出一种**以物体为中心的、跨模态统一的可操作可供性（actionable affordance）表示**，将“在哪里交互（visual）、如何抓取（grasp）、如何移动（trajectory）”三者显式编码，从而架起人类视频与机器人控制之间的桥梁。

### 2. 论文提出的方法论

- **核心思想**：从自我中心（egocentric）人类视频中自动提取三类可操作可供性，并训练一个基于大型视觉-语言模型（VLM）的统一基础模型 VLAff，同时预测视觉、抓取和轨迹可供性。
- **训练数据构建流程（数据生成管线）**：
  1. **数据准备**：利用已有自我中心视频数据集的语言描述和时间标注，在交互时间戳附近采样帧，并通过大型 VLM 查询交互关键帧、动作类别、物体类别和交互手部信息。
  2. **手-物交互提取**：使用手物检测器、分割模型、2D 手部关键点检测器，通过指尖与物体掩码的交集确定接触区域；用 MANO 参数重建 3D 手部网格；并对自我视角进行分割和修复（inpainting）以消除视觉偏差。
  3. **自我中心 SfM（运动恢复结构）**：对修复后的帧进行单目深度估计、相机姿态估计（过滤动态区域）、相机内参估计，并通过 3D 手部轨迹追踪获得接触前后的运动模式。
- **VLAff 模型架构**：
  - **基础组件**：以 Qwen2.5-VL 为 VLM 骨干，额外引入 DINOv2 视觉编码器以增强细粒度空间理解。
  - **特殊 token 设计**：在 VLM 词表中引入三类模块专用 token——`<SEG>`（视觉热图）、`<GRASP>`（抓取姿态）、`<p0>...<pN-1>`（轨迹离散 token）。
  - **三个解码器**：
    - 视觉可供性解码器：融合 DINOv2 特征与 `<SEG>` token 嵌入，生成像素级热图。
    - 抓取解码器：将 `<GRASP>` token 解码为 96 维 MANO 参数（全局腕部旋转 + 15 个局部关节旋转，采用 6D 旋转表示）。
    - 轨迹解码器：自回归生成轨迹 token，并通过空间分箱（spatial binning）将连续 6D 姿态离散化。
- **目标函数**（总损失）：
  - \( L_{total} = \lambda_v L_{visual} + \lambda_g L_{grasp} + \lambda_t L_{traj} \)
  - 视觉损失：Soft Dice Loss（处理热图不平衡问题）。
  - 抓取损失：Smooth L1 Loss。
  - 轨迹损失：标准交叉熵损失（自回归语言建模）。
- **推理阶段的轨迹优化策略**：
  - **上下文轨迹引导**：利用高能力 VLM（如 GPT）作为高层规划器，提供初始运动方向向量（三轴分量限定在 {−1, 0, 1}），用于引导第一个轨迹 token 的采样。
  - **基于采样的轨迹选择**：使用 nucleus sampling 生成 K 个候选轨迹，通过体素化碰撞检测和方向对齐的复合目标选择最优轨迹。
