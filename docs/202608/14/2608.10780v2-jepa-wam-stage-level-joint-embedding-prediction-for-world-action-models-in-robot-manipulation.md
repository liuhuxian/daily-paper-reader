## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射为跨多样化任务的动作。然而，现有方法通常将未来表示为固定且短暂的视频-动作块。这种短期未来捕捉用于动作执行的局部场景演化，但并未明确描述指定任务应如何从当前阶段推进到下一阶段的分阶段未来。因此，我们区分了机器人操作中两个互补的未来：用于捕捉局部场景演化的短期物理未来和用于表示任务进展的分阶段语义未来。我们提出了JEPA-WAM，它通过Stage-JEPA（一种以目标为条件的联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的总体成功率，并将成功执行轨迹中的平均执行步骤数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

- **问题提出**：通用机器人策略（Generalist Robot Policies）的目标是将多模态观测和语言指令映射为可执行动作。现有方法通常将“未来”表示为一个固定时长的短视频-动作块（short video-action chunk），这属于**短期物理未来**，能捕捉局部场景演化与接触动力学，但无法显式描述**任务进展**——即任务应从当前阶段推进到下一个有意义的语义状态。
- **核心矛盾**：预测一个合理的视频-动作轨迹，≠ 策略理解当前任务下一步应该达到什么状态。WAM（World Action Model）虽然显式建模了短期视觉未来，但任务相关的对象状态与关系变化仍是隐式的。
- **核心问题**：如何让机器人策略在生成局部动作之前，先预测“下一阶段任务进展”的语义目标？
- **解决思路**：区分两种互补的未来——
  - **短期物理未来**（short-term physical future）：局部视频-动作演化；
  - **阶段级语义未来**（stage-level semantic future）：下一个对象状态或关系目标。
  利用联合嵌入预测架构（JEPA），在潜在表征空间中（而非像素空间）预测下一阶段目标，避免像素级预测对表观细节的过度关注，使预测聚焦于任务完成的语义结构。

## 二、方法论：核心思想、关键技术细节与算法流程

### 1. 总体架构
JEPA-WAM 由两个顺序训练阶段组成，整体基于 Motus WAM 扩展，核心组件为 **Stage-JEPA**：

- **Stage I**：训练目标条件 JEPA 预测器（fθ），从当前观测和任务指令推断下一阶段潜在目标；
- **Stage II**：冻结 Stage-JEPA，训练 WAM，使其以预测的阶段潜变量为条件，生成短期视觉未来与动作块；
- **推理阶段**：两组件依序在滚动时域（receding-horizon）中闭环执行。

### 2. Stage I：阶段对构建与目标条件阶段预测

- **阶段边界自动构建（无需人工标注）**：
  - 在每条示教轨迹中每 8 帧采样候选中心；
  - 用冻结的 V-JEPA2 编码各中心周围的 64 帧切片，得到 clip 级和 token 级表征；
  - 通过局部窗口内的表征变化分数（clip 级欧氏距离与 token 级最大距离的归一化最大值）衡量状态变化强度；
  - 使用时间非极大值抑制（NMS），最多保留 5 个关键转移帧，加上首尾帧构成阶段边界序列 B = (b₀, …, b_L)；
  - 将每个阶段内的每个当前帧 t 与下一边界 bᵢ₊₁ 配对，构成密集训练对。
- **目标条件阶段预测**：
  - 使用冻结的 V-JEPA2 编码器分别编码当前切片和目标切片；
  - 可训练的预测器（由 V-JEPA2 预测器初始化）输出 token 级下一阶段预测，经池化与归一化后与目标潜变量做余弦相似度对齐；
  - 损失函数为：
    - L_stage = (1/B) Σ [1 − (ẑ_targetⁱ)ᵀ z_targetⁱ]
  - 仅优化预测器与指令适配器，编码器保持冻结。

### 3. Stage II：阶段条件 WAM 训练

- **WAM 基座**：Motus，一种混合 Transformer（Mixture-of-Transformers）架构，包含视频生成专家、动作专家、视觉-语言理解专家；视频专家由 Wan2.2 初始化，理解专家使用冻结 Qwen3-VL。
- **条件注入机制**：
  - 将 Stage-JEPA 输出的 token 表征做均值池化，经 MLP 映射到视频 token 维度；
  - 通过有界标量门控 α = 0.2σ(β)（初始化为 0.02）进行加性注入：X̂ᵥ = Xᵥ + αh；
  - 门控为全局共享标量，条件向量逐样本特定并被广播到所有视频 token。
- **辅助正则化**（防止阶段特征破坏视频模态表征）：
  - L = L_video + L_action + L_reg
  - L_reg = λ_g·α² + λ_ρ·(ρ − ρ₀)²，其中 ρ = ‖αh‖/‖Xᵥ‖ 为相对注入幅度，ρ₀ 为目标比例。

### 4. 闭环推理
- 维护因果 64 帧观测缓冲区（不足时重复最早帧填充）；
- 预测下一阶段潜变量：ẑ_target = fθ(H_t, l)；
- 以该潜变量为条件生成短期未来与动作块：(V̂_start, Â) = W_φ(o_t, s_t, l, ẑ_target)；
- 执行动作块后更新缓冲区，重复该过程；阶段边界仅在训练期使用，推理时无访问权限。

## 六、主要结论与发现

1. **主结果**：JEPA-WAM 在干净配置下达到 91.42% 平均成功率，随机化配置下 89.08%，总体 90.25%，显著优于 Motus（88.66%/87.02%）及其他 VLA 基线。
2. **类别差异**：
   - 在**交接（Handover）**、**定点放置**、**容器收纳**、**排列与堆叠**、**工具使用**等依赖明确任务进展变化的类别上提升最大；
   - **抓取与抬升**类别中 JEPA-WAM 略低于 Motus（92.60% vs 94.20%），作者归因于该类任务主要依赖即时抓取几何和接触稳定性，阶段结构提供的互补信息较少；
   - **铰接/设备交互**中提升有限且随机化下略降，归因于该类别还依赖机构特定接触、约束运动和精确时序，间接条件注入的信号可能不足。
3. **消融结论**：
   - 去除 JEPA 分支导致最大性能下降（总体 87.23%→90.25%，差距 3.02%），说明阶段条件通路提供了 WAM 之外的额外信息；
   - 仅用阶段信号修改当前观测表征（不注入未来潜变量）性能下降（89.89%），验证了“注入未来目标”的必要性；
   - 去除 Stage-I 训练仍有竞争力（89.98%），说明预训练 V-JEPA2 预测器已提供部分通用视觉结构，但阶段目标训练仍带来稳定增益；
   - 去除门控正则化下降较小（89.88%），Sigmoid 有界门控本身已提供一定稳定性。
4. **执行效率**：
   - 全部 rollouts 平均 episode 长度从 156.28 步降至 132.80 步（-15.02%）；
   - 成功 rollouts 平均长度从 79.57 步降至 74.82 步（-5.97%），说明阶段引导可减少冗余纠正动作、更直接地完成任务。
5. **真实机器人**：Cube_Grasp 和 Power_Strip 的平均任务进展评分均优于 π0.5（平均 48.00 vs 41.50）。

## 七、优点

### 方法设计亮点
- **双时间尺度未来建模的提出**：清晰区分“局部物理演化”与“阶段语义进展”，概念有理论区分度且实用；
- **JEPA 的语义预测范式**：在潜空间预测阶段目标而非像素重建，天然规避了像素预测对表观细节和过渡时长的敏感性，更贴合任务完成语义；
- **自动阶段边界发现**：无需人工标注，利用冻结 V-JEPA2 表征变化 + NMS 自动推断阶段边界，可扩展性强；
- **轻量级条件注入与门控机制**：全局标量门控 α 使注入强度可控，辅助正则化防止阶段特征过度改写视频表征，设计简洁且有效；
- **两阶段训练策略**：先学语义目标再学局部实现，冻结 Stage-JEPA 避免细节损失干扰语义表征，训练范式清晰。

### 实验亮点
- **大规模仿真覆盖**：50 任务、10,000 次闭环评估，覆盖语义操作不同类别；
- **多维度评估体系**：成功率、消融、执行效率、阶段监督诊断、真机验证、可视化对比——评估视角完整；
- **诊断统计**：对自动构建的阶段监督进行边界长度、跨边界比例、切片重叠等定量分析，说明了监督构造的性质与潜在偏差来源，体现出实验严谨性。

- **效率分析混淆因素**：成功/失败 episode 混合的时长分析（156.28→132.80）中，失败提前终止或更快失败也可能缩短平均长度，需谨慎解读；文中的成功 rollout 指标更可靠。

### 方法本身的局限
- **V-JEPA2 的 64 帧窗口限制**：要求 64 帧输入，推理初期需要帧重复填充；中心化切片导致跨阶段边界信息泄漏和与目标切片重叠（84.67%/86.77% 跨边界比例，86.77% 切片重叠），训练目标本质上是“时间上下文化的阶段表示”而非严格外推，可能引入监督偏差；
- **阶段边界质量依赖特征质量**：边界检测基于 V-JEPA2 表征距离，不同任务/对象外观下边界语义是否准确未经人工验证标注评估；
- **推理延迟问题**：Stage-JEPA 与 Motus 串联推理，文中未报告实际推理延迟/FPS，未来的高频控制适用性存疑；
- **间接条件注入的局限**：门控注入仅作用于视频 token，未直接调制动作分支，对需要精确接触稳定的任务（如铰接交互）信号传递强度有限；
- **对“阶段”的定义依赖单一特征启发式**：NMS 保留最多 5 个关键帧，对阶段数多于 5 的长时任务可能欠拟合，缺少阶段数适应性机制。

### 应用限制
- 计算成本较高（8×A800 双阶段训练 + 编码器推理开销），部署到低算力边缘设备有挑战；
- RoboTwin 为合成生成的仿真环境，真实世界迁移仅 2 个任务验证，结论一般化需要更多真实场景支撑。
