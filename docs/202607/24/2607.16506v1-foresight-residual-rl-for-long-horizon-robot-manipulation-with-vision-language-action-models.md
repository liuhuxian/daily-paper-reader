## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在紧公差、高接触的装配任务中，由于长时程信用分配和子任务耦合，往往失败：当前技能在几何上成功的状态可能对后续技能脆弱。我们在冻结的VLA基础策略上展示了残差强化学习（RL）中的这种失效模式：恒定的稀疏成功奖励孤立地改进了每个子任务，但当技能链式组合时几乎没有提升，因为终端状态质量不受控。我们提出远见残差RL，通过用离线估计的远见值——基于当前子任务终端状态的条件未来子任务成功概率——来增强每个子任务的稀疏成功奖励，从而优化交接质量。具体来说，我们（i）从基础策略的终端状态图像训练一个视觉远见预测器，使用下游rollout统计进行标注，以及（ii）通过反向远见归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中一个基于扳手的螺母紧固三阶段装配任务（抓取、移动-插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持子任务成功率不变。这些结果强调，提升长时程性能需要塑造每个子任务产生的成功状态的质量，而不仅仅关注是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题**：长时程、高接触的机器人装配任务（如扳手拧紧螺母）中，将任务分解为多个子任务并分别训练策略是常见做法，但子任务之间存在因果耦合（例如插入后必须在旋转时保持插入状态），而标准残差强化学习（Residual RL）仅使用稀疏的成功奖励来独立优化每个子任务，导致终端状态质量不受控——即使每个子任务单独成功率很高，链式执行时全任务成功率却很低。
- **背景**：VLA（视觉-语言-动作）大模型如π₀提供了通用操作先验，但直接端到端训练或独立子任务训练都无法处理子任务间的依赖。过去方法如分布匹配（初始化重叠）只优化代理目标，而未直接优化全局任务成功概率。
- **核心洞察**：当前子任务的终端状态对后续子任务的成功概率存在显著差异，但标准奖励忽略了这一点。因此需要优化子任务“交接质量”（handoff quality），即终端状态的下游成功概率。

## 2. 论文提出的方法论

### 核心思想
- **远见残差强化学习（Foresight Residual RL）**：在残差策略训练中，将子任务自身的稀疏成功奖励乘上一个离线估计的**远见值（foresight value）**——即当前子任务终端状态导致后续子任务成功的概率。这样，残差策略会倾向于产生更有利于下游的终端状态，而非仅仅满足当前子任务的几何成功。

### 关键技术细节
1. **远见价值函数**：对于子任务k，定义其终端状态s的远见价值为未来所有子任务（k+1到K）的期望折扣最终子任务成功回报。论文中简化为单步近似（只考虑下一个子任务的成功概率）。
2. **视觉远见预测器**：训练一个图像输入的概率预测器p_ϕ，输入终端状态观测图像，输出下游子任务的成功概率。训练数据通过离线收集：使用基础VLA策略（π₀）滚动出N个成功的终端状态，每个状态再通过下游策略（已训练好的子任务k+1策略）进行K_rep次独立rollout，统计成功次数作为标签。使用二项式负对数似然损失进行训练。
3. **反向远见归纳（Backward Foresight Induction）**：从最后一个子任务K开始向前训练。对于子任务K（最后），直接使用标准稀疏成功奖励。对于前面的子任务k，先训练下游子任务k+1的策略（包括其残差），然后收集数据训练远见预测器p_ϕ，最后在训练子任务k的残差策略时，奖励设为 `r_t = β_k(s_{t+1}) · p_ϕ(o_{t+1})`，其中β_k是子任务k的成功谓词。
4. **残差策略**：在冻结的VLA基础策略之上添加一个小的残差项（α=0.1），使用PPO训练。残差网络输入仅使用腕部相机图像，经过DINOv2+CNN+LSTM+MLP输出动作修正。

### 算法流程概要（文字说明）
- 对于每个子任务边界，执行：
  - 用基础策略收集N个成功终端状态；
  - 对每个终端状态，用下游策略（已训练）做K_rep次rollout，获得成功计数；
  - 训练视觉远见预测器（二项式NLL）；
  - 使用该预测器作为奖励乘数，通过PPO训练当前子任务的残差策略。
- 训练顺序：从最后一个子任务开始，反向进行。

## 6. 论文的主要结论与发现

- **标准残差RL误导：** 提高子任务单独成功率但损害链式性能（子任务成功率从45.7%提升至92.2%，全任务从41.4%仅提升至54.5%，与端到端π₀持平）。
- **远见残差RL大幅提升：** 全任务成功率达到85.6%，相比标准残差提高31.1%，且子任务单独成功率几乎不变（说明改进来自终端质量而非子任务成功本身）。
- **关键机制：** 远见预测器引导残差策略产生更有利于后续的终端状态（抓取角对齐更好、插入更稳定），这在分布匹配等代理方法中无法直接优化。
- **后向归纳训练有效：** 先训练下游再训练上游，保证了远见估计的稳定。

## 8. 不足与局限

- **实验仅在仿真中进行**：真实世界的接触动力学、观测噪声、延迟等未验证，实际部署可能面临更大挑战（作者提及主要障碍是残差策略的在线RL，而非仿真-现实迁移）。
- **单一任务**：仅在三阶段螺母拧紧任务上验证，缺乏其他接触丰富任务（如插销、装配不同零件）的泛化。子任务分解方式为手动定义。
- **远见预测器的单步近似**：只考虑下一个子任务的成功，忽略更远期的依赖（虽然文中讨论可扩展，但未实现）。
- **对基础策略分布依赖**：预测器仅在基础策略的终端状态上训练，当残差策略优化后终端分布漂移可能超出预测器适用范围（作者认为小α限制了漂移，但未严格分析）。
- **计算成本**：虽然离线预测器训练快，但收集标注数据仍需大量仿真rollout（每个终端状态需K_rep=5次下游策略运行），且后向归纳要求先训练所有下游策略，增加了阶段依赖。
- **未对比分布匹配类方法**：如T-STAR、SCaR等，仅与标准残差和π₀对比，削弱了对“分布匹配代理”优势的证明。
