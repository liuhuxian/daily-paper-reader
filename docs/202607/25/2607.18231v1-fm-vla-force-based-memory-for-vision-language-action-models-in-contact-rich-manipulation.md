## 摘要
视觉-语言-动作（VLA）模型在机器人操作中实现了令人印象深刻的泛化能力，而近期引入记忆增强的VLA模型通过依赖历史图像或语言摘要，放宽了马尔可夫假设。基于视觉的记忆方法通过采样历史图像帧来处理这一问题，但计算成本高，且在时间事件在视觉上模糊时（例如多次按下按钮但动作幅度很小）存在根本性局限。我们提出FM-VLA，一种具有基于力记忆的VLA模型，能够对非马尔可夫且接触丰富的操作进行时间上下文推理。我们使用变分自编码器（VAE）对力时间序列进行预训练重建，将力历史编码为紧凑的力记忆令牌。通过将力的潜在表示和短状态历史作为额外的条件令牌注入动作专家模块，使得VLA能够利用累积的接触事件历史来指导操作。我们在三个依赖记忆的任务上评估FM-VLA，包括寻找隐藏的方块、按动按钮以及擦拭盘子指定次数。我们的轻量力记忆在极小的推理开销下实现了超过80%的成功率，显著优于基线方法。项目页面：https://qft-333.github.io/FM-VLA-Page/

## Abstract
Vision-language-action (VLA) models have achieved impressive generalization in robotic manipulation, and recent memory-augmented VLAs have relaxed the Markovian assumption by conditioning on past images or language summaries. Vision-based memory approaches address this by conditioning on sampled past image frames, but they are computationally expensive and fundamentally limited when temporal events are visually ambiguous, e.g., pushing a button multiple times with small movements. We propose FM-VLA, a VLA model with force-based memory, enabling temporal context reasoning for non-Markovian, contact-rich manipulation. We encode force histories into compact force memory tokens with a variational autoencoder (VAE) pretrained with force time series reconstruction. By projecting force latent representations and short state history as additional conditioning tokens to the action expert module, we enable VLAs to leverage accumulated contact event history to guide manipulation. We evaluate FM-VLA on three memory-dependent tasks, including finding a hidden block, pressing a button, and wiping a dish for a specific number of times. Our lightweight force memory achieves over 80% success rate with minimal inference overhead, significantly outperforming baseline approaches. Project page: https://qft-333.github.io/FM-VLA-Page/

- **核心问题**：现有视觉-语言-动作（VLA）模型多基于马尔可夫假设（仅依赖当前观测），无法处理依赖历史上下文的非马尔可夫任务（如计数、跟踪交互进度）。基于视觉记忆的方法（如记忆库、多尺度记忆）在处理视觉模糊场景（如按钮小幅按压）时计算开销大且性能受限。
- **整体含义**：FM-VLA首次提出利用**力（wrench）信号作为长期记忆**，为VLA模型提供接触事件的清晰、轻量级历史表示，从而在接触丰富的操作任务中实现高效的时间上下文推理。

## 论文提出的方法论

### 核心思想
- 将力历史通过预训练的变分自编码器（VAE）压缩为紧凑的力记忆令牌，并联合短窗口状态历史令牌，作为条件注入动作专家模块，使VLA能利用累积接触事件指导动作生成。

### 关键技术细节
1. **两阶段训练**：
   - **阶段1（力VAE预训练）**：使用Perceiver-IO架构的VAE，在力时间序列重建目标（masked-ELBO + 自由位正则化）上无监督预训练，得到通用力的潜在空间。编码器输出K=8个潜在令牌，维度dz=96。
   - **阶段2（VLA微调）**：冻结VAE编码器（仅用后验均值，无重参数化），将力记忆令牌（经线性投影）和短窗口状态历史令牌（由零初始化的线性层投影）拼接到动作专家后缀（noisy action tokens之后），使用π0.5基模型进行流匹配微调（50k步）。

2. **力历史处理**：
   - 一阶指数移动平均（EMA, α=0.3）降噪。
   - 训练时随机预填充高斯噪声（最长10秒），避免模型利用历史长度作为时间进度线索；推理时禁用。

3. **短状态历史**：取最近0.9秒的关节状态窗口（10帧，步长3），投影为单个令牌。

4. **注入方式**：动作专家序列为 [noisy action tokens (30个) ∥ force memory tokens (8个) ∥ state window token (1个)]，保持原有RoPE位置。

## 论文的主要结论与发现

1. **力记忆有效性**：FM-VLA平均成功率83.3%，显著优于π0.5（27.8%）、TA-VLA（22.2%）、π-MEM（53.7%），尤其在Buttons和Wipe任务（力主导）上优势巨大（72.2% vs 33.3%, 77.8% vs 50.0%）。
2. **力+状态必须协同**：仅力记忆（25.9%）或仅状态记忆（40.7%）均无法达到完整性能。
3. **VAE优于直接端到端**：GRU（33.3%）和Q-Former（57.4%）均不及VAE（83.3%），说明预训练重建任务有助于提取任务相关宏观结构。
4. **推理效率极高**：FM-VLA仅比基线π0.5增加3.3ms延迟（64.0 vs 60.7ms），远低于视觉记忆（39-129ms增加）。

## 优点（方法或实验设计的亮点）

- **首次将力信号作为长期记忆**：克服视觉模糊问题，为VLAs提供全新的状态表征维度。
- **两阶段训练设计巧妙**：VAE预训练提供任务无关、紧凑的力表示，避免端到端训练中的过拟合和梯度消失；冻结编码器后微调高效稳定。
- **轻量级注入**：仅增加8个力令牌+1个状态令牌，推理开销极小，适合实时机器人控制。
- **实验设计全面公平**：严格控制变量（相同基模型、超参数、数据），对比多种记忆范式，并进行了充分的消融分析。

## 不足与局限

1. **VAE固定8令牌瓶颈**：对于超长时间任务（数百次接触事件），可能需要分层或自适应压缩机制。论文未评估更短或更长历史的处理能力。
2. **VAE仅在当前数据集预训练**：未利用大规模异构机器人力数据（如大规模抓取数据集），可能限制泛化性（论文在局限中也提到）。
3. **任务规模有限**：仅三个任务，每个任务18次试验，统计显著性可能受样本量影响；未在多种机器人平台或多传感器类型上验证。
4. **依赖力传感**：要求手腕装有6轴力/力矩传感器，且需较高采样率（100Hz），对硬件成本有要求。
5. **未与语言记忆或混合记忆方法对比**：如MEM结合语言总结，或MemoryVLA，本文仅对比视觉记忆和短窗口力。
6. **应用限制**：仅适用于接触丰富的任务，对于无接触或视觉主导的任务可能不必要。
